# BTC 반감기 사이클 트레이딩

## 핵심 개념

BTC는 약 4년마다 반감기(Halving)를 겪으며 공급 충격 → 가격 급등 → 버블 붕괴의 패턴을 반복한다.

### 반감기 사이클 타임라인

```
반감기 발생 (4월/5월경)
  → 6~12개월: 축적 구간 (공급 감소 선반영 시작)
  → 12~18개월: 강한 상승 (기관/개인 매수 동반)
  → 18~24개월: ATH 도달 + 알트시즌
  → 24~36개월: 하락/횡보 (약세장)
```

### 사이클별 실적

| 반감기 | 날짜 | 이전 저점 | ATH | 상승률 |
|--------|------|-----------|-----|--------|
| 1차 | 2012-11 | $2 | $1,200 | 60,000% |
| 2차 | 2016-07 | $200 | $20,000 | 10,000% |
| 3차 | 2020-05 | $3,800 | $69,000 | 1,800% |
| 4차 | 2024-04 | $15,500 | $100,000+ | 650%+ (진행 중) |

> 수익률 감소 추세: 사이클마다 약 1/5~1/6로 감소 (시총 증가로 자연스러운 현상)

## 드러켄밀러식 BTC 사이클 매매

### 매크로 + 사이클 결합 프레임

```
강세 조건 체크리스트:
[ ] 반감기 후 6~18개월 구간
[ ] 연준 금리 인하 사이클 또는 동결
[ ] DXY 하락 추세
[ ] BTC 온체인: 장기 보유자 비중 증가 (HODL Waves)
[ ] 기관 매수 확인 (ETF 순유입 양전환)
[ ] 200일 이평선 위에서 거래

→ 5개 이상 충족 시: 강력 매수 신호
```

### 진입 전략

**1단계 진입 (반감기 전 저점 매수):**
- 반감기 6~12개월 전 시장 조정 시 적립식 매수
- 반감기 후 첫 3개월 내 강한 돌파 시 추가 매수

**2단계 피라미딩 (추세 확인 후):**
```
200일 이평선 회복 후 첫 돌파 → 1차 진입 (40%)
전 고점 돌파 + 거래량 확인 → 2차 추가 (30%)
ATH 신기록 돌파 → 3차 추가 (20%)
```

### 청산 전략

**조기 경보 신호 (50% 청산 고려):**
- NUPL (Net Unrealized Profit/Loss) > 0.75 (극도의 탐욕)
- 연준 금리 인상 재개 신호
- BTC 주봉 20주 이평선 하향 돌파

**강제 청산 신호 (전량 청산):**
- 주봉 기준 전 고점 -20% 이탈
- 온체인: 장기 보유자 대규모 분배 시작
- 매크로 급변 (QT 강화, 유동성 위기)

## 핵심 교훈

1. **반감기를 믿되, 매크로를 더 믿어라** — 2022년 금리 인상이 사이클을 단축
2. **ATH는 끝이 아니다** — 역사적으로 ATH 돌파 후 2~3배 더 상승
3. **탐욕 지수 90+ = 청산 준비** — 대중이 알 때 기회는 끝난다
4. **사이클 후반 알트코인 집중** — 수익률 극대화 구간
5. **절대 원칙**: 약세장에서 알트코인 장기보유 금지 (BTC 대비 -90% 일상)
