## 5대 성공 사례 핵심 요약

### Case 1: Bitcoin 초기 채택자 (2010–2013)
- **수익률**: 2013년 진입 기준 ~116,400% (ATH $1,165)
- **핵심**: 기술 이해 + 장기 보유 (2011년 -93% 폭락 버팀)
- **대표**: Winklevoss 형제 $11M 진입 → 현재 ~$4.5B 가치
- **따라하기**: 불가능 (시총 규모 한계)

### Case 2: Ethereum ICO (2014 → 2021)
- **수익률**: $0.311 → $4,891 = **약 15,730배**
- **핵심**: 스마트 컨트랙트 플랫폼 가능성 7년 신뢰
- **따라하기**: 신흥 L1 초기 진입으로 구조적 유사성 가능

### Case 3: DeFi Summer 2020
- **수익률**: COMP $90 → $372 (3주 내), TVL $3B 돌파
- **핵심**: 프로토콜 출시 첫 주 유동성 공급 → 거버넌스 토큰 수령
- **따라하기**: 다음 DeFi 사이클에서 반복 가능

### Case 4: NFT (BAYC 2021)
- **수익률**: 0.08 ETH ($192) → 128 ETH ($360,000) = 1,875배
- **핵심**: 커뮤니티 신호 + 문화적 가치 인식
- **따라하기**: 다음 NFT 사이클 형태 미확정

### Case 5: L1 알트코인 (SOL, AVAX, MATIC)
- **수익률**: SOL $0.50 → $260 = **52,000%**, AVAX $0.88 → $144 = 16,264%
- **핵심**: BTC 반감기 후 180일 내 알트 시즌 + 실제 DeFi/NFT 생태계 활성화
- **따라하기**: ★★★★☆ 패턴 반복됨
