# 내러티브 기반 투자 — 소로스식 재귀성 전략

## 핵심 철학

> "시장은 현실을 반영하는 것이 아니라, 참가자들의 기대가 현실을 만든다." — 조지 소로스

소로스의 **재귀성(Reflexivity) 이론**은 암호화폐 시장에서 가장 강하게 작동한다:
- 내러티브 → 가격 상승 → 내러티브 강화 → 더 많은 매수 → 자기실현적 예언
- 이 사이클을 **먼저 인식하고 올라타는 자**가 승자

## 내러티브 생명주기

```
1. 씨앗 단계 (내부자/OG만 앎)
   - GitHub 활동, 소규모 Discord
   - 가격: 거의 변동 없음
   - 기회: 최고지만 발굴 어려움

2. 성장 단계 (얼리어답터 진입)
   - CT(Crypto Twitter) 인플루언서 언급 시작
   - 가격: +50~200%
   - 기회: 최적의 진입 구간 ← 여기가 핵심

3. 과열 단계 (주류 진입)
   - 코인데스크, 유튜브 특집 방송
   - 가격: +500~2,000%
   - 기회: 이익 실현 구간

4. 소멸 단계 (FOMO 대중 진입)
   - 주류 미디어 1면, 엄마도 아는 코인
   - 가격: 정점 후 급락
   - 기회: 없음. 오히려 공매도 기회
```

## 내러티브 발굴 방법

### 실전 신호 탐지 채널

**온체인/소셜 데이터:**
```
Santiment → Social Volume 급증 코인 탐색
LunarCrush → AltRank, Social Score
Dune Analytics → 사용자 증가 프로토콜
DefiLlama → TVL 급증 섹터
```

**정보 흐름:**
```
1차: GitHub 활동 (개발자)
2차: CT 인플루언서 (Murad, Ansem, Cobie 등)
3차: 한국 투자 커뮤니티 (디시, 클리앙)
4차: 유튜브/TikTok (대중화 = 매도 신호)
```

### 내러티브 검증 체크리스트

```
[ ] 기술적으로 실현 가능한가? (vs 순수 마케팅)
[ ] 실제 사용자 증가가 있는가?
[ ] 기관/VC 투자가 연결되는가?
[ ] 규제 친화적인가?
[ ] 경쟁자 대비 차별점이 있는가?
[ ] 토크노믹스가 홀더에게 유리한가?
```

## 2024~2025 성공한 내러티브 사례

### Case 1: AI 에이전트 코인 (+5,000%)
```
씨앗: 2023년 LangChain/AutoGPT 열풍 → 온체인 AI 가능성 논의
성장: Virtuals Protocol 출시 (2024 Q3) → CT에서 급속 확산
과열: AI 에이전트 파생 토큰 수백개 런칭 (2025 Q1)
소멸: 대부분 -90% 하락, VIRTUAL만 부분 생존
```
**교훈**: 섹터 리더(VIRTUAL) 집중, 파생 토큰 조심

### Case 2: 트럼프/밈코인 슈퍼사이클
```
씨앗: 2024년 트럼프 재선 → "친암호화폐 정부" 기대감
성장: TRUMP, MELANIA 토큰 런칭 (2025 1월)
과열: 수천개 정치 테마 밈코인 범람
소멸: TRUMP 토큰 -80% (1주일 만에)
```
**교훈**: 밈코인은 며칠 단위 트레이딩, 장기보유 금지

### Case 3: RWA (실물자산 토큰화) 장기 내러티브
```
씨앗: BlackRock BUIDL 펀드 온체인 런칭 (2024 3월)
성장: 국채 토큰화 TVL 10억→50억 달러 (2024)
과열: 진행 중 (2025~2026 예상)
```
**교훈**: 기관급 내러티브는 사이클이 길다 (2~3년)

### Case 4: 솔라나 생태계 부활
```
씨앗: FTX 붕괴로 SOL $8 (2022년 바닥)
성장: 밈코인(BONK, WIF) 생태계 폭발 (2024 Q1)
과열: SOL $260+ 도달, ETH 비교 내러티브 (2024 Q4)
```
**교훈**: 생태계 전체 내러티브 + 밈코인 = 강력한 시너지

## 소로스식 진입/청산 전략

### 진입: 내러티브 + 가격 action 동시 확인

```
Step 1: 내러티브 식별 (위 채널 모니터링)
Step 2: 가격 확인 — 최저점 대비 아직 -70% 이상? 또는 ATH 직전?
Step 3: 온체인 — 큰손 축적 확인 (Nansen Smart Money)
Step 4: 커뮤니티 — 긍정적 감정 증가 중이나 아직 광기 아님
Step 5: 리스크 설정 후 분할 진입
```

### 청산: 재귀성의 반대 방향을 감지

```
청산 신호:
- 모든 주류 미디어에 나왔다
- "이번엔 다르다" 류의 글 범람
- 신규 토큰이 수백개 생기기 시작
- 이익 내는 지갑 비율 > 90%
- CT 인플루언서들이 다음 내러티브로 이동
```

## 핵심 교훈

1. **내러티브를 먼저 사고, 코인을 나중에 산다** — 섹터 선택이 종목 선택보다 중요
2. **대중화 = 청산 신호** — 유튜버가 추천하면 이미 늦었다
3. **재귀성을 활용하라** — 오르기 때문에 오른다, 내리기 때문에 내린다
4. **내러티브 생명주기 6~18개월** — 너무 오래 보유하면 소멸 구간 맞는다
5. **손절은 내러티브 소멸 시** — 단순 가격 하락이 아니라 이야기가 끝날 때 팔아라
