# 따라하기 전략 — 대가 전략 통합 실전 가이드

## 개요

주식 시장 대가들의 검증된 전략을 암호화폐 시장에 통합 적용하는 실전 가이드.
각 대가의 핵심 원칙을 "지금 당장 실행 가능한" 형태로 정리한다.

> "대가의 원칙을 이해하되, 암호화폐 시장의 특성(24시간, 고변동성, 내러티브 주도)에 맞게 변형하라."

## B. 대가 전략별 즉시 실행 가이드

### 드러켄밀러 — 매크로 체크리스트

**지금 당장 해야 할 것:**
1. FOMC 점도표 확인 → 2026년 잔여 인하 횟수와 시장 기대 비교
2. DXY 주봉 차트 → 하락 추세 지속 여부 (반등 전환 시 비중 축소)
3. M2 증가율 → 연준 대차대조표 + 글로벌 유동성 흐름 체크

**실전 적용:**
```
매크로 강세 유지 시: BTC 포지션 30~50% 유지, 확신 높으면 집중
매크로 전환 신호 시: 48시간 내 포지션 50% 이상 축소
핵심 원칙: "방향이 맞으면 크게, 틀리면 즉시 철수"
```

### 리버모어 — BTC/알트 피라미딩 진입 레벨

**지금 당장 해야 할 것:**
1. BTC 직전 피봇 포인트(ATH/주요 저항선) 식별 → 돌파 시 40% 진입
2. XRP $1.50 돌파 시 30% 추가, $1.65 돌파 시 20% 추가 (피라미딩)
3. 알트코인은 피라미딩 간격 +10~15%로 넓게, 포지션 BTC의 절반

**피라미딩 실전 템플릿:**
```
BTC 피라미딩:
  1차: 주요 저항선 돌파 확인 — 40%
  2차: +7% 상승 확인 — 30%
  3차: +14% 상승 확인 — 20%
  손절: 직전 피봇 -5% 이탈

알트코인 피라미딩:
  1차: 섹터 리더 돌파 확인 — 40%
  2차: +12% 상승 확인 — 30%
  3차: +25% 상승 확인 — 20%
  손절: 진입가 -20% 또는 BTC -5% 급락 시
```

### CANSLIM 변형 — DeFiLlama TVL 급증 스크리닝

**지금 당장 해야 할 것:**
1. DeFiLlama TVL 변화율 Top 10 프로토콜 스크리닝 (7일/30일 기준)
2. Token Terminal에서 Revenue QoQ +25% 이상 프로토콜 필터링
3. 해당 섹터 리더 코인(TVL/거래량 1~3위)만 후보 리스트에 추가

**CANSLIM 코인 스크리닝 체크리스트:**
```
C — 프로토콜 수익(Revenue) QoQ +25%+
A — TVL/수수료 연간 성장 추세 확인
N — 메이저 업그레이드 또는 대형 파트너십 발표
S — 유통량 적고 저인플레 (토크노믹스)
L — 해당 섹터 TVL/거래량 1~3위
I — VC 투자, ETF 신청, 기관 채택 여부
M — BTC/ETH 상승 추세 확인 (200일선 위)
→ 5/7 이상 충족 시 진입 고려
```

### 튜더 존스 — 계좌 대비 1% 리스크 포지션 계산

**지금 당장 해야 할 것:**
1. 전체 계좌 잔고 확인 → 1% = 최대 허용 손실금액 산출
2. 각 포지션별 손절 폭 설정 → 포지션 크기 역산
3. 5:1 리스크/리워드 미충족 거래 전부 제거

**포지션 크기 계산기:**
```
계좌 잔고: $X
1% 리스크 = $X * 0.01

BTC 포지션 (손절 -8%):
  포지션 크기 = ($X * 0.01) / 0.08 = $X * 0.125
  → 계좌의 12.5%

알트코인 포지션 (손절 -15%):
  포지션 크기 = ($X * 0.01) / 0.15 = $X * 0.067
  → 계좌의 6.7%

5:1 리워드 확인:
  BTC: 목표 +40% 이상 (8% * 5)
  알트: 목표 +75% 이상 (15% * 5)
```

## C. 포트폴리오 템플릿

### 3가지 프로필별 자산 배분

| 자산 | 보수형 | 중립형 | 공격형 |
|------|--------|--------|--------|
| BTC | 50% | 40% | 25% |
| ETH | 20% | 20% | 20% |
| 대형 알트 (SOL, XRP 등) | 10% | 15% | 20% |
| 섹터 리더 알트 | 0% | 10% | 20% |
| 내러티브 탐색 (소액) | 0% | 5% | 10% |
| 현금 (USDT/USDC) | 20% | 10% | 5% |

### 사이클 단계별 조정

```
사이클 초중반 (현재 추정 위치 근처):
  → 중립형 기준 운용
  → 과열 지표 출현 시 보수형으로 전환

사이클 후반 (NUPL > 0.6, F&G > 80):
  → 보수형 전환, 현금 30%+ 확보
  → 알트 비중 대폭 축소

약세장 전환 확인:
  → BTC/ETH만 소량 유지 (20%)
  → 현금 80%
  → 알트코인 전량 청산
```

### 프로필 선택 기준

```
보수형: 자본 $5,000 미만 또는 경험 1년 미만
중립형: 자본 $5,000~$50,000, 매크로 강세 확인 시
공격형: 자본 $50,000+, 사이클 초중반 + 매크로 5/6 강세 신호
```

## D. 주간 모니터링 체크리스트

매주 일요일 또는 월요일에 확인해야 할 온체인 + 매크로 지표 7가지:

### 1. BTC 200일 이평선 위치
```
확인: BTC 현재가 vs 200일 이평선
판단: 위 = 강세, 아래 = 약세 전환 경고
소스: TradingView 또는 Binance 차트
액션: 200일선 하향 이탈 시 알트 전량 청산 검토
```

### 2. BTC 도미넌스
```
확인: BTC.D (CoinMarketCap/TradingView)
판단:
  > 60% → BTC 집중, 알트 최소화
  50~60% → ETH/대형 알트 비중 확대
  < 50% → 알트시즌 진입, 섹터 로테이션
```

### 3. Fear & Greed Index
```
확인: alternative.me/crypto/fear-and-greed-index
판단:
  < 25 (극도의 공포) → 매수 기회 탐색
  25~75 (중립) → 기존 전략 유지
  > 75 (탐욕) → 이익 실현 시작
  > 90 (극도의 탐욕) → 현금 비중 50%+ 확보
```

### 4. NUPL (Net Unrealized Profit/Loss)
```
확인: Glassnode 또는 LookIntoBitcoin
판단:
  < 0.25 → 매수 구간
  0.25~0.5 → 낙관 (보유)
  0.5~0.75 → 경계 (이익 실현 준비)
  > 0.75 → 청산 구간 (강제 비중 축소)
```

### 5. 연준/FOMC 동향
```
확인: FedWatch Tool (CME), FOMC 회의록
판단:
  금리 인하 지속 → 강세 유지
  인하 중단/인상 전환 → 즉시 비중 축소
  점도표 변화 → 시장 기대와 괴리 시 포지션 조정
```

### 6. DXY (달러 인덱스)
```
확인: TradingView DXY 주봉
판단:
  하락 추세 → 위험자산 강세 (BTC 우호)
  반등 전환 → 암호화폐 약세 선행 신호
  주요 지지/저항 돌파 → 매크로 방향 재평가
```

### 7. 거래소 BTC 순유출입
```
확인: CryptoQuant Exchange Netflow
판단:
  순유출 (거래소 → 지갑) → 축적 신호, 강세
  순유입 (지갑 → 거래소) → 매도 압력, 경계
  대규모 순유입 3일 연속 → 단기 하락 경고
```

## F. 마이클 AI 자동화 아이디어

### 1. BTC 도미넌스 모니터링 스크립트

**개요:** Binance API로 BTC 도미넌스 변화를 추적하여 알트시즌 진입/이탈 알림

```
구현 방식:
1. Binance /api/v3/ticker/24hr 에서 BTC 및 주요 알트 시가총액 계산
2. BTC.D = BTC 시총 / 전체 시총 * 100
3. 임계값 기반 알림:
   - BTC.D 60% 상향 돌파 → "BTC 독주 구간, 알트 축소 권고"
   - BTC.D 50% 하향 돌파 → "알트시즌 진입 신호, 섹터 로테이션 시작"
   - BTC.D 45% 하향 돌파 → "알트시즌 본격화, 내러티브 섹터 집중"
4. 주기: 4시간마다 체크 (cron: 0 */4 * * *)
5. 알림: Telegram 브리핑으로 전송
```

**필요 데이터:**
- Binance 24hr ticker (전 종목)
- CoinGecko /global API (BTC 도미넌스 직접 제공, 대안)

### 2. Fear & Greed 지수 임계값 알림

**개요:** F&G 지수가 극단값 도달 시 자동 알림 + 포지션 조정 권고

```
구현 방식:
1. alternative.me API에서 F&G 지수 조회
   GET https://api.alternative.me/fng/?limit=1
2. 임계값 설정:
   - F&G < 20 → "극도의 공포! 매수 기회 탐색 권고"
   - F&G > 80 → "과열 주의! 이익 실현 시작 권고"
   - F&G > 90 (3일 연속) → "강제 비중 축소 신호! 현금 50%+ 확보"
```
