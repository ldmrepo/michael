# 알트코인 섹터 로테이션 전략

## 개요

BTC 강세 → ETH 강세 → 대형 알트 → 중소형 알트 → 밈코인 순서로 자금이 이동하는 패턴을 활용한다.

## BTC 도미넌스와 알트시즌

### 로테이션 사이클

```
Phase 1: BTC 독주 (BTC 도미넌스 상승)
  - BTC만 오르고 알트는 BTC 대비 하락
  - 전략: BTC에 집중, 알트 최소화

Phase 2: ETH/대형 알트 (BTC 도미넌스 정체/하락 시작)
  - BTC 도미넌스 65% → 55% 구간
  - ETH, BNB, SOL 등 대형 알트 상승
  - 전략: ETH 비중 확대

Phase 3: 알트시즌 (BTC 도미넌스 45% 이하)
  - 중소형 알트코인 폭발적 상승
  - 전략: 내러티브 기반 섹터 집중

Phase 4: 밈코인/잡코인 (막판 버블)
  - 모든 코인이 오르는 구간 (FOMO 최고조)
  - 전략: 이익 실현 시작
```

### BTC 도미넌스 기준 배분

| BTC 도미넌스 | BTC | ETH | 대형 알트 | 중소형 알트 |
|-------------|-----|-----|-----------|-------------|
| > 60% | 70% | 20% | 10% | 0% |
| 50~60% | 50% | 30% | 15% | 5% |
| 40~50% | 30% | 30% | 25% | 15% |
| < 40% | 20% | 20% | 30% | 30% |

## 섹터별 내러티브 로테이션

### 주요 암호화폐 섹터

```
인프라 레이어:
  L1 (ETH, SOL, AVAX, SUI) — 기반 플랫폼
  L2 (ARB, OP, MATIC, BASE) — 확장성 솔루션

애플리케이션 레이어:
  DeFi (UNI, AAVE, CRV, GMX) — 탈중앙화 금융
  NFT/게임 (IMX, RON, GALA) — 디지털 소유권
  AI (TAO, NEAR, FET, AGIX) — AI + 블록체인

투기성:
  밈코인 (DOGE, SHIB, PEPE) — 순수 커뮤니티/모멘텀
```

### 섹터 선택 기준 (린치식 텐배거 접근)

1. **내러티브 강도**: 주류 미디어 + 소셜에서 언급량 급증
2. **실사용 지표**: TVL, 활성 지갑 수, 거래량 증가
3. **진입 타이밍**: 내러티브 시작점 (대중화 전)
4. **토크노믹스**: 인플레이션율, 언락 스케줄 확인
5. **섹터 내 리더**: 해당 내러티브에서 가장 강한 코인

## CANSLIM을 알트코인에 적용

### 코인 선별 7가지 기준 (변형)

```
C — Current Earnings: 프로토콜 수익(Revenue) 급증 (QoQ +25%+)
A — Annual Earnings: TVL/수수료 연간 성장 추세
N — New Product: 메이저 업그레이드, 신규 기능, 대형 파트너십
S — Supply: 유통량 적고 최대 발행량 낮음, 저인플레
L — Leader: 해당 섹터 TVL/거래량 1~3위
I — Institutional: 기관 매수 (VC 투자, ETF 신청, 국가 채택)
M — Market Direction: BTC/ETH 상승 추세 시에만 진입
```

### 실전 스크리닝 방법

```
1. DeFiLlama에서 TVL 급증 프로토콜 탐색
2. Token Terminal에서 Revenue/P/S 지표 확인
3. Coingecko 트렌딩 + 거래량 급증 코인 체크
4. Twitter/TG에서 KOL 언급 빈도 확인
5. 차트: 최저점 대비 -70%~-85% 구간 또는 ATH 돌파 직전
```

## 진입/청산 전략

### 진입 원칙

**알트코인 진입 체크리스트:**
```
[ ] BTC 도미넌스 하락 추세 확인
[ ] 해당 섹터 내러티브 확인 (뉴스, 소셜)
[ ] 코인 자체 거래량 7일 평균 200% 이상 급증
[ ] BTC 대비 차트 반등 확인 (BTC/ALT 비율)
[ ] 포지션 크기: 단일 알트 최대 5~10%
```

### 청산 원칙

**이익 실현:**
- +50%: 초기 투자금 전량 회수 (나머지는 공짜 포지션)
- +100~200%: 50% 추가 청산
- 내러티브 소멸 시: 전량 청산 (미련 없이)

**손절:**
- 진입가 대비 -20% (알트는 변동성으로 -8% 적용 불가)
- BTC 급락(-5%+ 일봉) 시 알트 즉시 청산
- 섹터 내 리더 코인이 먼저 무너지면 청산 신호

## 2024~2025 알트시즌 성공 사례 분석

### 섹터별 최고 수익률 (4차 사이클)

| 섹터 | 대표 코인 | 저점 대비 고점 | 내러티브 |
|------|-----------|---------------|---------|
| AI 에이전트 | VIRTUAL, AI16Z | +5,000%+ | 자율 AI 에이전트 |
| 밈코인 | DOGE, PEPE, WIF | +500~2,000% | 트럼프/커뮤니티 |
| L1 신흥 | SUI, APTOS | +800%+ | Move 언어 생태계 |
| DeSci | BIO, RIF | +1,000%+ | 탈중앙화 과학 |
| RWA | ONDO, POLYX | +400%+ | 실물자산 토큰화 |

### 교훈

1. **AI 내러티브 + 코인 = 10~50배**: ChatGPT 열풍이 AI 코인으로 연결
2. **정치/문화 밈 = 폭발적 단기**: 트럼프 밈코인은 단기 100배 후 -90%
3. **RWA는 기관급 내러티브**: BlackRock, Franklin Templeton 참여 = 신뢰도
4. **섹터 리더만 살아남는다**: 2위, 3위는 약세장에서 -95%

## 핵심 교훈

1. **알트는 BTC 상승장에서만 매수** — 하락장 알트 보유 = 자살행위
2. **섹터 리더 1~2개 집중** — 3위 이하는 리더보다 훨씬 못함
3. **내러티브 생명주기** = 발생 → 과열 → 소멸 (6~18개월)
4. **이익 실현은 빠를수록 좋다** — 알트는 하락이 상승보다 10배 빠름
5. **밈코인은 도박** — 전체 포트의 5% 이하로 엄격히 제한
