# Jesse Livermore — 모멘텀 피라미딩 전략

## 핵심 철학

> "월스트리트에 새로운 것은 없다. 투기는 오래됐다. 오늘 일어나는 일은 과거에도 일어났고 미래에도 일어날 것이다."

제시 리버모어는 1929년 대공황에서 1억 달러($) 수익을 낸 전설적 트레이더.
핵심 전략은 **추세를 확인하고, 이익이 나는 방향으로만 포지션을 늘리는 피라미딩**이다.

---

## 핵심 개념: 피봇 포인트 (Pivot Point)

리버모어는 주가가 특정 가격에서 돌아서는 "피봇 포인트"를 중심으로 매매했다.

**피봇 포인트 유형:**
- **진입 피봇**: 추세가 시작되는 첫 돌파점
- **계속 피봇**: 추세 중 발생하는 눌림목 반등점
- **반전 피봇**: 추세가 끝나는 신호

```
피봇 확인 방법:
1. 주가가 중요 저항선(이전 고점, 박스권 상단)을 돌파
2. 거래량이 평균 대비 150% 이상 증가
3. 돌파 후 되돌림 없이 3일 이상 유지
→ 진입 피봇 확인
```

## 피라미딩 전략

### 기본 원리

**"이기는 포지션에만 베팅을 추가한다"**

피라미딩은 수익이 나는 포지션에 추가 매수하는 기법이다.
손실 포지션에 물타기하는 것과 정반대 개념.

### 피라미딩 구조

```
초기 매수: 전체 목표 포지션의 40%
  → 주가 +5~7% 상승 확인
추가 매수 1: 전체의 30%
  → 주가 추가 +5~7% 상승 확인
추가 매수 2: 전체의 20%
  → 주가 추가 +5~7% 상승 확인
최종 매수: 전체의 10%
```

**예시 (BTC $80,000 진입):**
```
1차 진입: $80,000 — 포지션의 40% (예: 0.4 BTC)
BTC $85,600 도달 (+7%)
2차 추가: $85,600 — 포지션의 30% (예: 0.3 BTC)
BTC $91,600 도달 (+7%)
3차 추가: $91,600 — 포지션의 20% (예: 0.2 BTC)
BTC $98,000 도달 (+7%)
4차 추가: $98,000 — 포지션의 10% (예: 0.1 BTC)
최종 평균 단가: ~$86,000
```

---

## 진입 조건

1. **추세 확인**: 주/월봉 기준 명확한 상승 추세
2. **피봇 돌파**: 의미 있는 저항선 (이전 고점, 52주 신고가) 돌파
3. **거래량 동반**: 돌파 시 거래량 평균 대비 150% 이상
4. **시장 환경**: 시장 전체가 상승 추세일 때 (역행 종목 피하기)
5. **섹터 리더십**: 해당 섹터에서 가장 강한 종목 선택

**진입 타이밍 (정확한 진입점):**
```
- 전날 고점 + 0.5~1% 돌파 시점
- 장중 거래량 급증 시 (오전 10시~11시 가장 많은 기회)
- 하루 안에 돌파 미완성 시 진입 취소
```

---

## 청산 조건

### 손절 (절대 원칙)
- 초기 진입: 피봇 포인트 아래 -7~8%
- 피라미딩 후: 가장 최근 추가 매수가 대비 -3~4%
- **규칙 예외 없음** — 리버모어도 이 규칙을 어겨 파산했다

### 이익 실현
**트레일링 스탑 방식:**
```
+20% 수익 도달 시: 매입가에 스탑 설정
+40% 수익 도달 시: +20% 포인트에 스탑 상향
+60% 수익 도달 시: +40% 포인트에 스탑 상향
```

**강제 청산 신호:**
- 일봉 기준 20일 이평선 하향 이탈 (3일 연속)
- 전고점 하회
- 거래량 없는 급등 (배분 신호)
- 리버모어 원칙: "주가가 설명 없이 하락하면 이유가 있다"

---

## 리버모어의 4가지 시장 규칙

1. **추세와 싸우지 마라**: 상승장에선 매수, 하락장에선 공매도 또는 현금
2. **모든 달걀을 한 바구니에 담아라 (그리고 잘 지켜봐라)**: 분산이 아닌 집중
3. **타이밍이 전부다**: 좋은 주식을 잘못된 타이밍에 사면 손실
4. **감정을 제거하라**: 시스템대로 실행, hope/fear 배제

## 코인 시장 적용

### BTC 피라미딩 시나리오

```
조건: BTC 전 고점(ATH) 돌파 확인
  - 주봉 기준 이전 ATH 돌파 + 거래량 2배 이상
  - 시장 전체 상승 (ETH, 알트 동반 상승)

진입 계획:
  1차: ATH 돌파 확인 후 (예: $70,000) — 40%
  2차: $75,000 (+7%) 도달 시 — 30%
  3차: $80,000 (+7%) 도달 시 — 20%
  4차: $86,000 (+7%) 도달 시 — 10%

손절: 각 단계에서 직전 피봇 -5% 이탈 시
```

### 알트코인 피라미딩 주의사항

- 알트코인은 BTC 보다 변동성 3~10배 높음
- 피라미딩 간격을 +10~15%로 넓게 설정
- 포지션 크기를 BTC의 절반으로 제한
- BTC 하락 전환 시 알트 즉시 청산

## 핵심 교훈 요약

1. **수익 포지션에 추가, 손실 포지션은 즉시 손절**
2. **진입 타이밍은 돌파 순간** — 기다렸다 올라타면 늦다
3. **시장 전체 추세를 먼저 확인**
4. **인내심** — 좋은 포지션은 오래 가져가라
5. **규칙 위반이 파산을 만든다** — 리버모어 자신의 교훈
