# Stanley Druckenmiller — 매크로 트렌드 전략

## 핵심 철학

> "수익이 나면 베팅을 늘리고, 손실이 나면 베팅을 줄여라. 하지만 내가 틀렸을 때는 아주 빠르게 철수한다."

드러켄밀러는 퀀텀 펀드(소로스)의 수석 운용역으로 30년간 연평균 30% 수익을 달성했다.
핵심은 **매크로 방향을 먼저 잡고, 확신이 생기면 대규모 집중 베팅**이다.

---

## 전략 구조

### 1단계: 매크로 환경 진단

```
체크리스트:
[ ] 중앙은행 금리 방향 (인상/동결/인하 사이클)
[ ] 달러 인덱스 (DXY) 추세
[ ] 채권 수익률 곡선 형태 (정상/역전/평탄화)
[ ] 글로벌 유동성 지표 (M2 증가율, 연준 대차대조표)
[ ] 선행 경기 지표 (PMI, 소비자 신뢰지수)
[ ] 기업 이익 성장률 방향
```

**강세 환경 신호:**
- 금리 인하 사이클 시작 또는 진행 중
- DXY 하락 추세
- 유동성 확장 (M2 증가)
- PMI > 50 반등

**약세 환경 신호:**
- 금리 인상 최고점 도달 전
- 수익률 곡선 역전 심화
- 유동성 수축
- PMI < 50 추세적 하락

---

### 2단계: 섹터/자산 선정

매크로 방향이 결정되면 그 환경에서 가장 크게 움직일 자산을 선택한다.

| 매크로 환경 | 선호 자산 |
|-------------|-----------|
| 금리 인하 + 달러 약세 | 성장주, 금, 신흥국, 암호화폐 |
| 금리 인상 + 달러 강세 | 달러, 에너지, 원자재 |
| 경기 확장 | 소재, 산업재, 기술주 |
| 경기 침체 | 방어주, 채권, 금 |
| 스태그플레이션 | 에너지, 금, TIPS |

---

### 3단계: 진입 조건

**확신이 생겼을 때 크게 베팅한다 (드러켄밀러의 핵심)**

진입 조건:
1. 매크로 환경이 명확하게 한 방향 (3개 이상 신호 일치)
2. 기술적으로 지지/저항 돌파 확인
3. 시장이 아직 매크로 변화를 완전히 반영 안 한 상태
4. 리스크/리워드 비율 최소 1:3 이상

**포지션 크기 결정:**
- 확신도 높음: 포트폴리오 30~50%
- 확신도 중간: 포트폴리오 15~25%
- 확신도 낮음: 투자하지 않는다

---

### 4단계: 청산 조건

**손절:**
- 매크로 thesis가 틀렸다는 신호 출현 즉시 청산
- 기술적 주요 지지선 붕괴
- 진입가 대비 -8% (절대 원칙)

**익절:**
- 매크로 환경이 반전 신호
- 목표 자산이 선행지표 대비 과매수
- 시장 컨센서스가 본인 thesis와 일치하기 시작 (대중화 = 기회 소멸)

## 코인 시장 적용

### BTC/ETH 매크로 프레임

```
유동성 확장 사이클:
  연준 금리 인하 시작 → BTC 상승 리드
  DXY 하락 → 위험자산 선호 → 암호화폐 강세
  M2 증가 → 자산 인플레이션 → BTC 수혜

유동성 수축 사이클:
  연준 금리 인상 → BTC 약세 선행
  DXY 강세 → 달러 환류 → 암호화폐 약세
```

### 실전 적용 예시

```
시나리오: 연준 금리 인하 사이클 진입 확인
→ 매크로 신호: FOMC 점도표 하향, DXY 하락 전환, PMI 반등
→ 선택 자산: BTC (디지털 금 + 위험자산 혼합)
→ 진입: 기술적 돌파 확인 후 계좌 40% 집중
→ 손절: DXY 반등 전환 또는 BTC -8% 이탈
→ 목표: 매크로 사이클 전환점까지 보유 (수개월~수년)
```

### 드러켄밀러 코인 관점 (실제 발언 기반)

- BTC를 "디지털 금"으로 인정, 금보다 선호 발언 (2020)
- 기관 채택 증가 = 매크로 자산으로 진화 중
- 유동성 민감도가 주식보다 높아 매크로 베팅 수단으로 적합

## 핵심 교훈 요약

1. **방향이 맞을 때 크게 베팅** — 소심한 분산은 평범한 수익만 만든다
2. **틀리면 즉시 인정** — ego보다 자본 보존
3. **매크로가 먼저** — 기업/코인 분석보다 큰 그림이 더 중요
4. **기회는 드물다** — 연 3~5번의 큰 기회에 집중
5. **시장의 유동성을 따라가라** — 중앙은행이 시장을 만든다
