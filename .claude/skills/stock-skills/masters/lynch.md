# Peter Lynch — 텐배거 발굴 전략

## 핵심 철학

> "주식 시장에서 돈을 잃는 것은 주식 때문이 아니다. 위의 12개 층에서 당신이 내리기 전에 엘리베이터가 3층에 멈추는 것처럼, 당신이 팔기 전에 주식이 올라버리는 것이다."

피터 린치는 마젤란 펀드를 운용하며 13년간 연평균 29% 수익을 달성했다.
핵심 전략은 **일상생활에서 투자 아이디어를 발굴하고, 충분히 오래 보유하는 것**이다.

---

## 텐배거 (10-Bagger) 개념

**텐배거** = 투자 원금 대비 10배 수익을 안겨주는 주식

```
린치의 발견:
- 평생 투자에서 10~15개의 텐배거만 있으면 충분
- 대부분의 위대한 주식은 "지루한" 업종에서 나온다
- 월스트리트 분석가가 아직 발견 못한 주식이 기회
```

---

## 6가지 주식 분류

린치는 투자 전 주식을 6가지 유형으로 분류했다.

### 1. 저성장주 (Slow Growers)
```
특징: GDP 수준 성장, 안정적 배당
예시: 유틸리티, 통신
전략: 배당 목적으로만 보유
텐배거 가능성: 낮음
```

### 2. 대형 우량주 (Stalwarts)
```
특징: 연 10~12% 성장, 안정적
예시: 코카콜라, P&G
전략: 30~50% 수익 시 교체
텐배거 가능성: 낮음, 하락장 방어용
```

### 3. 고성장주 (Fast Growers) — 텐배거 핵심
```
특징: 연 20~25% 성장, 소형주
예시: 스타벅스 초창기, 홈데포 초창기
전략: 성장 스토리가 유효한 한 장기 보유
텐배거 가능성: 높음

발굴 포인트:
- 이제 막 두 번째 도시에서 성공한 체인점
- 닳고 닳은 업종에서 혁신적 방법 도입
- 아직 전국 확산이 안 된 지역 강자
```

### 4. 경기순환주 (Cyclicals)
```
특징: 경기에 따라 등락 반복
예시: 자동차, 철강, 항공
전략: 경기 저점에서 매수, 고점에서 매도
타이밍이 핵심 — 잘못된 타이밍 = 큰 손실
```

### 5. 회생주 (Turnarounds)
```
특징: 파산 위기 또는 큰 위기에서 회복 중
예시: 크라이슬러 (1980년대), 애플 (1997년)
전략: 회생 스토리 확인 후 소규모 포지션
텐배거 가능성: 매우 높음, 리스크도 매우 높음
```

### 6. 자산주 (Asset Plays)
```
특징: 숨겨진 자산이 주가에 미반영
예시: 부동산, 자회사 가치
전략: 자산 가치 > 시가총액 확인
```

## 텐배거 발굴 방법

### 생활 속 투자 아이디어

린치의 핵심 인사이트: **소비자로서 먼저 경험하라**

```
발굴 질문:
1. "이 가게/제품을 왜 나는 계속 쓰는가?"
2. "내 주변 사람들도 다 쓰는가?"
3. "아직 전국/전세계에 퍼지지 않았는가?"
4. "경쟁자가 쉽게 따라할 수 없는가?"

발굴 장소:
- 쇼핑몰 (어떤 매장에 줄이 서나?)
- 직장 (어떤 소프트웨어를 매일 쓰나?)
- 병원 (어떤 치료제/장비가 혁신적인가?)
- 레스토랑 (어디가 항상 만석인가?)
```

### 텐배거 후보 체크리스트

```
필수 조건:
[ ] EPS 성장률 > 20% (3년 연속)
[ ] PEG Ratio < 1.0 (성장 대비 저평가)
[ ] 부채비율 < 30%
[ ] 현금흐름 플러스
[ ] 내부자 매수 (임원이 자사주 매입)

보너스 조건:
[ ] 기관 보유 비율 < 30% (아직 저평가)
[ ] 월스트리트 분석가 커버리지 없음 또는 부정적
[ ] 지루하고 촌스러운 이름의 회사
[ ] 독점적 틈새 시장 보유
[ ] 소비자 브랜드 충성도 높음
```

### PEG Ratio 활용

```
PEG = PER / 연간 EPS 성장률

PEG < 0.5: 극히 저평가 (강력 매수 신호)
PEG 0.5~1.0: 저평가 (매수 고려)
PEG 1.0: 적정 가치
PEG > 2.0: 과대평가

린치: "PEG 1 이하에서 사고, 2 이상에서 팔아라"
```

## 진입 조건

```
매수 시점:
1. PEG < 1.0
2. 성장 스토리가 아직 초기 (전국 확산 전)
3. 기관 보유 < 30%
4. 분기 실적이 예상 상회
5. 내부자 매수 확인

매수 방법:
- 소규모로 시작 (2~5%)
- 스토리 확인되면 분할 매수
- 텐배거 후보는 충분히 오래 보유
```

## 청산 조건

### 스토리가 변했을 때

```
린치의 핵심: "주가 목표치보다 스토리를 추적하라"

매도 신호 (스토리 훼손):
- 성장이 기대보다 훨씬 낮음
- 주요 경쟁자 진입으로 해자 약화
- 경영진 교체 + 전략 혼란
- 과도한 부채 증가
- 새로운 사업 다각화 (핵심 역량 이탈)
- PEG > 2.0 도달 (스토리는 좋지만 이미 반영됨)
```

### 린치의 "팔지 마라" 원칙

```
팔면 안 되는 이유:
- 단순히 주가가 올랐다고 (텐배거는 계속 오른다)
- 시장 전체가 하락한다고 (좋은 주식은 회복한다)
- 심리적으로 불안하다고

팔아야 하는 이유:
- 스토리가 근본적으로 변함
- 더 좋은 PEG의 다른 주식 발견
- 자금이 급히 필요함 (부득이한 경우)
```

## 코인 시장 적용

### 린치식 코인 발굴

```
생활 속 발굴:
- "내가 매일 쓰는 dApp이 있나?" (실사용 프로토콜)
- "주변 개발자들이 어떤 체인에 빌딩하나?" (개발자 활동)
- "어떤 NFT/토큰이 특정 커뮤니티에서 필수품이 됐나?"

텐배거 코인 조건:
- 실제 사용자와 TVL 성장
- 토큰 이코노믹스: 공급 감소 + 수요 증가
- 섹터 초기 (L1/L2 경쟁에서 차별화)
- 대형 기관 미발견 상태
- 개발자 활동 활발 (GitHub 커밋)

PEG 코인 대안:
- P/S Ratio (시총 / 프로토콜 수익)
- P/TVL Ratio (시총 / 총 잠긴 가치)
- NVT Ratio (네트워크 가치 / 거래량)
  → 낮을수록 저평가
```

### 알트코인 텐배거 사례 패턴

```
공통 패턴:
1. 특정 사용 사례에서 명확한 1위
2. 기관 발견 전 단계 (시총 $100M~$1B)
3. 커뮤니티 주도 성장
4. 토큰 공급량 감소 메커니즘

성공 조건:
- BTC 강세장 진입 확인 후 매수
- 섹터 내 1~2위 프로젝트 선택
- 6개월~2년 보유 계획
- 포지션: 계좌의 3~10% (리스크 관리)
```

## 핵심 교훈 요약

1. **일상에서 투자 아이디어를 찾아라** — 월스트리트보다 먼저 발견
2. **스토리를 추적하라, 주가가 아니라** — 스토리가 유효하면 보유
3. **PEG 1 이하의 성장주만** — 성장 대비 저평가가 핵심
4. **텐배거는 너무 일찍 팔지 마라** — 소심한 청산이 큰 기회를 날린다
5. **지루한 업종, 촌스러운 이름을 주목하라** — 경쟁이 적은 곳에 기회
