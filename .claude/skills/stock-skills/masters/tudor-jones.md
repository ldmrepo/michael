# Paul Tudor Jones — 리스크 관리 전략

## 핵심 철학

> "가장 중요한 것은 공격적으로 수비하는 것이다. 나는 매일 아침 일어나 내 모든 포지션이 틀렸다고 가정한다."

폴 튜더 존스는 1980년대 초부터 현재까지 연평균 20%+ 수익을 달성한 매크로 트레이더.
핵심 철학은 **자본 보존이 수익 창출보다 우선**이다.

---

## 5:1 리스크/리워드 원칙

튜더 존스의 가장 유명한 원칙:

```
"나는 5:1 리스크/리워드 비율만 찾는다.
 5달러를 벌기 위해 1달러를 위험에 건다.
 20%만 맞아도 손익분기점을 달성한다."
```

**실전 적용:**
```
목표 수익: $500
최대 허용 손실: $100

진입 전 계산:
- 목표가: 현재가 + 예상 상승폭
- 손절가: 현재가 - (목표 상승폭 / 5)
- 비율 < 5:1이면 거래하지 않는다
```

## 포지션 크기 결정 (핵심)

### 1% 리스크 규칙

```
계좌 잔고 × 1% = 최대 허용 손실금액

예시: 계좌 $10,000
→ 최대 허용 손실 = $100/거래

BTC 매수, 손절 -5% 설정:
포지션 크기 = $100 / 5% = $2,000
→ 전체 계좌의 20%만 투입
```

### 변동성 기반 포지션 크기 조정

```
높은 변동성 자산 (BTC, 알트코인):
- 손절 폭 확대 → 포지션 크기 축소
- 계좌의 5~15%

낮은 변동성 자산 (SPY, 우량주):
- 손절 폭 좁음 → 포지션 크기 확대
- 계좌의 15~30%
```

## 시장 타이밍 전략

### 200일 이평선 규칙

```
튜더 존스의 간단한 시장 필터:

매수 가능:
- 가격 > 200일 이평선
- 200일선이 상승 방향

매수 금지:
- 가격 < 200일 이평선
- 200일선이 하락 방향

통계: 가격이 200일선 아래일 때 시장은
      평균 수익률 마이너스, 리스크 2배
```

### 피봇 고점/저점 분석

```
튜더 존스는 중요한 시장 전환점을 예측하는 데 집중:

강세 → 약세 전환 신호:
1. 가격이 이전 구조적 고점을 갱신하지 못함
2. 거래량 감소하며 신고가 도달
3. 시장 내부 약화 (리더 종목 이탈)
4. 스마트머니 분배 패턴

약세 → 강세 전환 신호:
1. 패닉 셀 이후 거래량 급감
2. 하락 시 매수세 등장 (내부 강도 개선)
3. 방어주보다 성장주 회복 선행
```

## 드로우다운 관리 규칙

### 월 -10% 도달 시 규칙

```
월 손실이 -10% 도달 시:
1. 모든 포지션 즉시 절반 청산
2. 신규 포지션 진입 금지
3. 다음 달까지 포지션 크기 50% 감소

월 손실이 -15% 도달 시:
1. 모든 포지션 전량 청산
2. 2주간 거래 중단 (강제 휴식)
3. 무엇이 잘못됐는지 철저히 분석
```

### 연속 손실 규칙

```
3연속 손절 발생 시:
1. 하루 거래 중단
2. 시장 환경 재평가
3. 포지션 크기 반으로 축소 후 재시작

5연속 손절 발생 시:
1. 1주일 거래 중단
2. 전략 재검토
3. 아주 작은 포지션으로 재시작 (감각 회복)
```

## 손절 실행 심리

### 튜더 존스의 손절 원칙

```
"손실은 감정이 아닌 시스템으로 결정한다."

손절 실행 체계:
1. 진입 전 손절가 미리 설정 (주문 동시 입력)
2. 손절가 도달 시 즉시 자동 청산
3. 청산 후 다시 분석 (감정 개입 없음)
4. 같은 날 재진입 금지 (24시간 쿨다운)

손절 후 금지 행위:
- 손절가 하향 조정 ("조금만 더 기다리자")
- 손절 후 즉시 재진입 ("본전 만회")
- 평균 단가 낮추기 (물타기)
```

## 거시 환경 + 기술적 결합

### 튜더 존스 분석 프레임

```
Level 1: 거시 환경 (방향 결정)
  - 금리 사이클
  - 유동성 환경
  - 지정학적 리스크

Level 2: 섹터/자산 선택
  - 매크로에 가장 민감한 자산
  - 상대 강도 분석

Level 3: 기술적 진입
  - 200일선 필터
  - 리스크/리워드 5:1 확인
  - 포지션 크기 계산

Level 4: 리스크 관리
  - 사전 손절가 설정
  - 드로우다운 한도 확인
  - 포트폴리오 상관관계 점검
```

## 코인 시장 적용

### BTC/알트 리스크 관리

```
BTC 포지션:
- 계좌의 최대 25% (고변동성 감안)
- 손절 -8~-10%
- 목표 +40~+50% (5:1 비율 유지)

알트코인 포지션:
- 계좌의 최대 10%
- 손절 -10~-12%
- 목표 +60~+70%

월간 손실 한도:
- BTC/알트 합산 -15% 시 전량 청산
- 크립토 시장 전체 하락장 확인 시 현금화
```

### 코인 시장 200일선 필터

```
BTC 200일선:
- BTC > 200일선: 알트 매수 가능
- BTC < 200일선: 알트 매수 금지, BTC도 축소

실전:
BTC 200일선은 강력한 bull/bear 경계선
역사적으로 200일선 위 = 강세장, 아래 = 약세장
```

## 핵심 교훈 요약

1. **손실 제한이 수익 창출보다 우선** — 살아남아야 기회가 온다
2. **5:1 리스크/리워드만 선택** — 불리한 게임에 참여하지 않는다
3. **200일선이 분기점** — 이 선 아래에서는 매수하지 않는다
4. **드로우다운 한도를 지켜라** — 감정이 아닌 시스템
5. **연속 손절 후 쉬어라** — 망가진 심리로 거래하면 더 잃는다
