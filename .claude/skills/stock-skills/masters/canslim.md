# CANSLIM — William O'Neil 성장주 선별 전략

## 핵심 철학

> "위대한 주식은 위대한 실적과 위대한 주가 행동이 결합된다."

윌리엄 오닐이 개발한 CANSLIM은 수십 년간 검증된 성장주 선별 시스템이다.
7가지 기준 중 6가지 이상 충족 시 매수를 고려한다.

---

## 7가지 기준 (CANSLIM)

### C — Current Earnings (현재 분기 실적)

```
기준:
- 최근 분기 EPS 성장률 > 25% (전년 동기 대비)
- 매출 성장률 > 20%
- 어닝 서프라이즈 (실제 > 예상)

강한 신호:
- EPS 성장률 > 50%
- 연속 2분기 이상 가속화

제외 조건:
- EPS 마이너스
- 성장률 둔화 추세
```

### A — Annual Earnings (연간 실적 성장)

```
기준:
- 3년 연속 EPS 성장
- 연간 EPS 성장률 > 25%
- ROE > 17%

최고급 신호:
- 3년 평균 성장률 > 40%
- ROE > 25% + 부채비율 낮음
```

### N — New Products/Management/Highs (신제품/신경영/신고가)

```
"N" 요소 확인:
- 혁신적 신제품 또는 서비스 출시
- 새로운 경영진 (특히 창업자 복귀)
- 52주 신고가 돌파 (중요!)
- 신규 시장 진입
- 규제 변화 수혜

O'Neil의 핵심 통찰:
"주식의 신고가는 약점이 아니라 강점이다.
 신고가를 기피하는 투자자는 돈을 잃는다."
```

### S — Supply and Demand (수급)

```
공급 측:
- 유통 주식수 적을수록 유리 (소형주 선호)
- 자사주 매입 활발한 기업
- 내부자 보유 비율 높음 (임원이 주식 보유)

수요 측:
- 거래량 증가 (평균 대비 40~50% 이상)
- 기관 매수세 증가
- 스폰서십 확대 (기관 보유 비율 증가)

위험 신호:
- 내부자 집중 매도
- 거래량 없는 주가 상승
```

### L — Leader or Laggard (리더 여부)

```
선택 기준:
- RS Rating (상대 강도) > 80
- 섹터 내 1~2위 종목
- 같은 섹터 2위보다 훨씬 강한 종목

제외:
- 섹터 평균보다 약한 종목
- "따라가기" 매수

RS Rating 80 이상 = 시장 대비 상위 20%
RS Rating 95 이상 = 최상위 5% (최고급 후보)
```

### I — Institutional Sponsorship (기관 지원)

```
확인 사항:
- 뮤추얼펀드 보유 증가 추세
- 우수한 실적의 기관이 보유
- 최근 2분기 기관 보유 증가

주의:
- 기관 과포화 (90% 이상 기관 보유) = 리스크
- 기관 청산 신호 = 즉시 경계
```

### M — Market Direction (시장 방향)

```
O'Neil의 핵심 발견:
"대부분의 주식은 시장 전체와 함께 움직인다.
 75%의 주식이 시장 방향을 따른다."

확인 방법:
- 나스닥/S&P500 추세 확인 (200일 이평선 위/아래)
- Follow-Through Day (FTD) 확인
- Distribution Day 수 모니터링

진입 금지 조건:
- 시장 전체가 하락 추세
- FTD 없이 반등 구간
- Distribution Day > 5일 (2주 내)
```

## 매수 전략: 올바른 베이스에서 돌파 매수

### 베이스 유형

**컵 앤 핸들 (Cup with Handle):**
```
형태: U자형 하락 후 반등 → 작은 조정(핸들) → 돌파
기간: 7주~65주
깊이: -12~-35% (이상적), -50% 초과 시 실패 위험 높음
핸들 깊이: 전체 컵의 -5~-12%
매수 포인트: 핸들 상단 + 10센트
```

**플랫 베이스 (Flat Base):**
```
형태: 횡보 박스권 (편차 ±15% 이내)
기간: 5주 이상
매수 포인트: 박스 상단 돌파
```

**더블 바텀 (Double Bottom):**
```
형태: W자형 이중 바닥
두 번째 바닥이 첫 번째보다 약간 낮아야 함
매수 포인트: W 중간 고점 돌파
```

### 매수 실행

```
진입 조건:
1. 올바른 베이스에서 돌파
2. 돌파 당일 거래량 평균 대비 +40% 이상
3. 시장 환경이 상승 추세 (M 확인)
4. CANSLIM 기준 6개 이상 충족

포지션 크기:
- 최초 진입: 계획 포지션의 50~75%
- 돌파 후 +2~3% 추가 확인 시: 나머지 25~50%
```

## 청산 규칙

### 손절 (8% 원칙)

```
O'Neil의 철칙: 진입가 대비 -8% 도달 시 즉시 손절
예외 없음 — 이 규칙이 큰 손실을 막는다
```

### 이익 실현

```
기본 원칙:
- 20~25% 수익 시 3분의 2 청산 (특별 예외: 급등주)
- 최소 2개월 이상 보유 후 세금 우대 혜택 고려

보유 연장 조건 (8주 보유 규칙):
- 돌파 후 3주 내 20% 이상 상승 → 8주 보유 유지
- 이런 종목은 텐배거 가능성 높음
```

## 코인 시장 CANSLIM 적용

CANSLIM의 직접 적용은 어렵지만 개념 전환 가능:

| CANSLIM | 코인 적용 |
|---------|-----------|
| C (분기 실적) | TVL 성장, 프로토콜 수익, 활성 주소 증가 |
| A (연간 성장) | 생태계 성장 (Dapp수, 거래량 추세) |
| N (신제품) | 메이저 업그레이드, 신규 파트너십, 에어드랍 |
| S (수급) | 유통량 감소 (락업, 번), 기관 매수 |
| L (리더) | 섹터 내 시총 1~2위, BTC 대비 강세 |
| I (기관) | 헤지펀드, ETF 유입, 고래 지갑 증가 |
| M (시장) | BTC 추세 확인 (BTC > 200일선 시에만 매수) |

**코인 CANSLIM 진입:**
```
1. BTC 200일 이평선 위에서만 알트 매수
2. 섹터 내 리더 코인 선택 (BTC.D 하락 시 알트 강세)
3. 박스권 돌파 + 거래량 급증 확인
4. 기관 유입 신호 (대형 지갑 누적)
5. 손절: -8% (알트는 -10~-12% 적용 가능)
```

## 핵심 교훈 요약

1. **시장이 하락할 때는 현금이 최고의 포지션**
2. **신고가를 두려워하지 말라 — 신고가가 더 오른다**
3. **-8% 손절 규칙은 협상 불가**
4. **거래량이 없는 돌파는 가짜**
5. **1~2개의 섹터 리더에 집중하라**
