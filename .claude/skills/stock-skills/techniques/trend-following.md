# 추세 추종 (Trend Following)

## 핵심 원리

> "추세는 친구다. 추세가 끝날 때까지 추세를 따르라."

추세 추종은 가격이 한 방향으로 움직이는 추세를 확인하고, 그 방향으로 진입해 추세가 끝날 때까지 보유하는 전략이다. 예측이 아닌 **반응**이 핵심이다.

---

## 추세 확인 도구

### 이동평균선 (MA)

```
단기 추세: 20일 이평선
중기 추세: 50일 이평선
장기 추세: 200일 이평선

골든 크로스 (강세 신호):
  50일선이 200일선 상향 돌파 → 매수 고려

데드 크로스 (약세 신호):
  50일선이 200일선 하향 이탈 → 매도/공매도 고려

이평선 정렬 (완벽한 추세):
  20일 > 50일 > 200일 (모두 상승 방향) → 강한 상승 추세
```

### ADX (Average Directional Index)

```
ADX > 25: 추세 존재 (추세 추종 가능)
ADX > 40: 강한 추세
ADX < 20: 추세 없음 (추세 추종 금지, 횡보 전략 사용)

+DI > -DI: 상승 추세
-DI > +DI: 하락 추세
```

### MACD

```
MACD 시그널:
- MACD 라인이 시그널 선 상향 돌파 → 매수
- MACD 라인이 시그널 선 하향 이탈 → 매도

히스토그램:
- 히스토그램 증가 → 추세 강화
- 히스토그램 감소 → 추세 약화 (주의)
```

## 진입 조건

```
상승 추세 진입 (모두 충족 시):
[ ] 200일 이평선 위에 가격 위치
[ ] 50일 이평선이 200일 이평선 위
[ ] 20일 이평선이 50일 이평선 위 (삼중 정렬)
[ ] ADX > 25
[ ] 최근 눌림목에서 반등 확인 (추세선 지지)
[ ] 거래량 증가 동반

진입 타이밍:
옵션 1: 20일 이평선에서 눌림목 반등 시
옵션 2: 이전 스윙 고점 돌파 시
옵션 3: ADX > 25 전환 시점
```

## 청산 조건

### 트레일링 스탑

```
방법 1: 이평선 기반
  - 매수 포지션: 20일 이평선 하향 이탈 시 청산

방법 2: ATR 기반 트레일링 스탑
  진입 후 스탑 = 최고점 - (ATR × 3)
  최고점 갱신 시마다 스탑 자동 상향

방법 3: 고정 퍼센트
  진입가 대비 -10% 또는 최고점 대비 -15%
```

### 강제 청산 신호

```
- ADX 하락 + 가격 이평선 이탈
- 데드 크로스 발생
- 거래량 급감하며 추세선 이탈
- 뉴스/이벤트로 추세 환경 변화
```

## 코인 시장 적용

### BTC 추세 추종

```
BTC 일봉 추세 확인:
- BTC > 200일선: 상승 추세 (알트 매수 허용)
- BTC < 200일선: 하락 추세 (현금 또는 숏)

BTC 주봉 추세:
- 더 강력한 추세 신호
- 주봉 200일선 돌파 = 강세장 시작
- 주봉 200일선 이탈 = 약세장 진입

진입 예시:
1. BTC 주봉 200일선 돌파 확인
2. 일봉 20>50>200 정렬 확인
3. ADX > 25 확인
4. 눌림목(20일선 지지) 후 반등 시 진입
5. 스탑: 20일선 -2%
```

### 알트코인 추세 추종

```
추가 조건:
- BTC가 상승 추세일 때만 알트 롱
- BTC.D (비트코인 도미넌스) 하락 추세 = 알트 시즌

알트 ATR 기반 스탑:
- ATR이 BTC보다 3~5배 높음
- ATR × 4~5로 스탑 설정 (더 넓게)
- 포지션 크기 줄여 리스크 동일하게 유지
```

## 추세 추종 시스템 성과

```
역사적 통계:
- 승률: 35~45% (과반수는 손실)
- 수익 trade 평균 수익: +30~+50%
- 손실 trade 평균 손실: -5~-8%
- 기대값: 양수 (큰 수익이 작은 손실 여럿을 커버)

핵심 교훈:
"손실은 잦지만 작게, 수익은 드물지만 크게"
이것이 추세 추종의 수학적 엣지
```

## 2024~2025 코인 실전 사례

### Case 1: SOL 골든크로스 추세 추종 (2024 Q4)

```
배경: SOL이 2024년 9월 50일선이 200일선 골든크로스 ($140)
진입: $145 (20>50>200 삼중 정렬 + ADX 32)
피라미딩: $170 (ATH $260 향해 추세 지속) → 30% 추가
청산: 2025년 1월 $230 (20일선 하향 이탈 시 트레일링 스탑)
수익: +59% (3개월)
핵심: BTC 강세 + SOL 생태계(밈코인) 내러티브 동반 → 추세 강도 유지
```

### Case 2: BTC 반감기 후 추세 추종 (2024-2025)

```
배경: 2024년 4월 반감기 후, BTC $63K → 조정 → $54K (200일선 지지)
진입: $58,000 (2024년 9월, 200일선 반등 + ADX 28)
추가: $72,000 (이전 ATH $69K 돌파, 거래량 2배)
추가: $85,000 (트럼프 당선 후 급등, 추세 가속)
청산: $92,000 (2025년 2월, 20일선 하향 이탈)
수익: +58% (5개월)
핵심: 반감기 사이클 + 매크로(금리 인하) + 정치(친암호화폐 정부) 삼중 추세
```

### Case 3: 추세 추종 실패 — ETH 데드크로스 (2025 Q1)

```
배경: ETH $3,400에서 50일선이 200일선 데드크로스 (2025년 2월)
신호: ADX 35 (강한 하락 추세), ETH/BTC 비율 지속 하락
교훈: 데드크로스 발생 시 즉시 청산 또는 숏
      → ETH $3,400 → $1,900 (-44%, 2개월)
결론: 추세 추종의 "하락 추세에서는 현금" 원칙이 정확히 작동
```

## 흔한 실수

1. **추세 없는 구간에서 적용** — ADX < 20일 때 추세 추종은 실패
2. **너무 빠른 청산** — 약간의 되돌림에 겁먹고 청산
3. **너무 촘촘한 스탑** — 변동성에 맞지 않는 스탑
4. **진입이 늦음** — 추세 확인 후 너무 오래 기다리다 놓침
5. **역추세 포지션 동시 보유** — 방향 혼란 금지
