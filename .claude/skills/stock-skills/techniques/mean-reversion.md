# 평균 회귀 전략 (Mean Reversion)

## 핵심 원리

> "가격은 언제나 평균으로 돌아온다."

평균 회귀는 가격이 장기 평균에서 크게 벗어났을 때 다시 평균으로 돌아올 것이라는 통계적 원리를 이용한 전략이다. 추세 추종과 반대 방향으로 포지션을 잡는다.

**적용 시장**: 박스권 횡보장, 고변동성 후 안정화 구간, 스프레드 트레이딩

---

## 핵심 지표

### 볼린저 밴드 (Bollinger Bands)

```
설정:
- 중심선: 20일 이평선
- 상단 밴드: 중심선 + 2σ
- 하단 밴드: 중심선 - 2σ

신호:
- 가격이 상단 밴드 접촉/돌파 → 매도/숏 신호
- 가격이 하단 밴드 접촉/돌파 → 매수 신호
- 밴드 폭 축소 (스퀴즈) → 큰 움직임 임박

통계적 의미:
- 가격의 95%는 상/하단 밴드 내에 존재
- 밴드 이탈 = 통계적 이상 상태 → 회귀 확률 높음
```

### RSI (Relative Strength Index)

```
설정: 14일 RSI

과매수/과매도 기준:
RSI < 30: 과매도 → 매수 신호
RSI > 70: 과매수 → 매도 신호

더 강한 신호:
RSI < 20: 극단적 과매도 (강한 매수)
RSI > 80: 극단적 과매수 (강한 매도)

주의: 강한 추세에서는 RSI가 장기간 과매수/과매도 유지
→ 추세 확인 먼저! (ADX > 25이면 평균 회귀 사용 금지)
```

### 스토캐스틱

```
설정: %K(14), %D(3)

매수 신호:
%K, %D 모두 20 이하 → 20 이상으로 상향 돌파

매도 신호:
%K, %D 모두 80 이상 → 80 이하로 하향 이탈

%K가 %D를 돌파하는 시점이 정확한 진입점
```

## 진입 조건

### 하락 후 반등 매수 (Buy the Dip)

```
조건 (모두 충족):
[ ] ADX < 25 (추세 없음, 박스권)
[ ] 가격이 하단 볼린저 밴드 이탈 또는 접촉
[ ] RSI < 30 (과매도)
[ ] 캔들 반등 신호: 도지, 망치형, 역망치형
[ ] 거래량 증가 (패닉 셀 확인)

진입:
- 반등 캔들 확인 후 다음날 시가 매수
- 또는 당일 반등 확인 후 종가 매수

포지션 크기:
- 첫 진입: 계획의 50%
- RSI 20 이하 추가 하락 시: 나머지 50% 추가 (분할 매수)
```

### 상승 후 매도 (Sell the Rally)

```
조건 (모두 충족):
[ ] ADX < 25 (박스권)
[ ] 가격이 상단 볼린저 밴드 이탈 또는 접촉
[ ] RSI > 70 (과매수)
[ ] 캔들 천장 신호: 도지, 슈팅스타, 저녁별형
[ ] 거래량 감소 또는 평균 수준

진입:
- 천장 캔들 확인 후 매도 또는 숏
```

## 청산 조건

```
매수 포지션 청산:
1. 목표: 20일 이평선 (중심선) 회귀 시 절반 청산
2. 목표: 상단 볼린저 밴드 접근 시 나머지 청산
3. 손절: 진입가 대비 -5~-7%

매도/숏 포지션 청산:
1. 목표: 20일 이평선 회귀 시 절반 청산
2. 목표: 하단 볼린저 밴드 접근 시 나머지 청산
3. 손절: 진입가 대비 +5~+7%

강제 청산 (평균 회귀 실패 신호):
- ADX가 25 이상으로 급등 (추세 전환)
- 볼린저 밴드 이탈 상태에서 연속 3캔들 유지
- 뉴스/이벤트로 패러다임 변화
```

## 볼린저 밴드 스퀴즈 전략

박스권 후 큰 움직임 포착:

```
스퀴즈 확인:
- 볼린저 밴드 폭이 최근 6개월 최저 수준으로 수축
- 밴드 폭 = (상단 - 하단) / 중심선 × 100
- 폭 < 2~3%이면 스퀴즈 상태

스퀴즈 해소 후 방향:
- 가격이 상단 밴드 돌파 + 거래량 급증 → 롱 진입
- 가격이 하단 밴드 돌파 + 거래량 급증 → 숏 진입

주의: 스퀴즈 방향은 예측 불가, 돌파 방향 확인 후 진입
```

## 페어 트레이딩 (Pairs Trading)

상관관계 높은 두 자산 간 스프레드 평균 회귀:

```
예시: BTC/ETH 스프레드
- BTC/ETH 비율의 역사적 평균 계산
- 비율이 평균 + 2σ 이탈 → BTC 매도 + ETH 매수
- 비율이 평균으로 회귀 → 포지션 청산

코인 페어 아이디어:
- BTC/ETH
- ETH/SOL
- BNB/FTM (같은 생태계)

주의: 상관관계가 깨지면 큰 손실 가능
     정기적으로 상관관계 검증 필요
```

## 코인 시장 적용

### 알트코인 과매도 반등

```
BTC 하락 후 알트 과매도 반등:
- BTC 급락 이후 알트 RSI < 20
- 볼린저 밴드 하단 이탈
- BTC 안정화 확인 후 알트 분할 매수

주의사항:
- 하락 추세 중간에 반등 오인 금지
- BTC 추세 전환 확인 먼저
- 알트 개별 펀더멘털 확인 (프로젝트 생존 가능성)

평균 회귀 기간:
- 단기 (1~7일): 일봉 RSI 기반
- 중기 (1~4주): 주봉 RSI 기반
```

### 코인 강세장 내 조정 매수

```
강세장 내 건강한 조정 활용:
- BTC 상승 추세 유지 (200일선 위)
- 단기 -15~-25% 조정 발생
- RSI 40~50 수준 (과매도까지 안 감)
- 거래량 감소하며 조정

→ 이 구간은 추세 추종과 평균 회귀 결합
→ 조정 저점 확인 후 추세 방향 진입
```

## 평균 회귀의 한계

```
실패 조건 (사용 금지):
1. 강한 추세 시장 (ADX > 25)
2. 뉴스/이벤트로 패러다임 변화
3. 유동성 위기 (레버리지 청산 연쇄)
4. 기업/프로젝트 근본 문제 발생

"다르게 보이는 것이 사실 다를 수 있다"
→ 과매도 상태가 계속 더 하락할 수 있음
→ 반드시 손절 규칙 지킬 것
```

---

## 핵심 교훈 요약

1. **박스권에서만 사용** — 추세가 있으면 추세 추종이 우선
2. **분할 매수** — 한 번에 전부 진입하지 않는다
3. **손절 필수** — 평균 회귀 실패 시 손실 제한
4. **ADX 확인 먼저** — ADX > 25이면 이 전략 사용 금지
5. **거래량 확인** — 패닉 셀 + 거래량 급증이 최고의 신호
