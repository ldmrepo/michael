# 돌파 매수 전략 (Breakout)

## 핵심 원리

> "저항이 지지가 된다. 공급 구역을 돌파하면 새로운 수요 구역이 형성된다."

돌파 매수는 가격이 중요한 저항선(수평선, 추세선, 전고점 등)을 돌파할 때 진입하는 전략이다. 돌파 후 이전 저항이 지지로 전환되어 상승 가속도가 붙는 원리를 이용한다.

---

## 돌파의 유형

### 1. 수평 저항선 돌파

```
유형:
- 이전 고점 돌파 (Resistance Breakout)
- 52주 신고가 돌파 (All-Time High Breakout)
- 박스권 상단 돌파

확인 방법:
1. 종가 기준 이전 고점 + 0.5% 이상
2. 당일 또는 다음날 가격 유지 확인
3. 거래량 기준: 평균 대비 150% 이상

가짜 돌파 (Fakeout) 구분:
- 종가 기준으로 돌파 여부 확인
- 거래량 동반 없으면 가짜 가능성 높음
- 돌파 후 3일 내 저항선 아래로 복귀 = 가짜
```

### 2. 박스권 돌파

```
박스권 기간: 최소 4~6주 이상
박스 깊이: -15~-30% 이내

조건:
- 동일한 저항 수준에서 2회 이상 거절
- 조정 시 거래량 감소 (분배 없음)
- 돌파 시 거래량 급증

박스 높이 = 최소 목표:
박스 상단 + 박스 높이 = 최소 가격 목표
예: 박스 $80~$100 → 돌파 목표 $120
```

### 3. 추세선 돌파

```
하락 추세선 돌파 (반전):
- 2개 이상 고점을 연결한 하락 추세선
- 추세선 상향 돌파 + 거래량 증가
→ 추세 반전 신호, 매수 기회

상승 추세선 복귀 후 반등:
- 상승 추세선으로 눌림목
- 추세선 위에서 지지 확인 후 반등
→ 추세 계속, 분할 추가 매수
```

### 4. 52주 신고가 돌파

```
가장 강력한 돌파 신호:

조건:
- 52주 신고가 + 2% 이상 돌파
- 거래량 평균 대비 200% 이상
- 시장 환경 양호 (나스닥 상승 추세)

이유가 강력한 이유:
- 52주 고점 위에는 매도 물량 없음
- 모든 보유자가 수익 상태 → 심리적 저항 없음
- 기관이 주시하는 중요한 기술적 레벨
```

## 진입 전략

### 즉시 진입 (돌파 당일)

```
시점: 돌파 당일 거래량 급증 확인 후
장점: 가장 유리한 진입가
단점: 가짜 돌파 위험

조건:
1. 장중 거래량이 평균의 2배 이상
2. 가격이 저항선 + 1% 이상 위에 위치
3. 시장 전체가 하락하지 않는 상황

진입: 저항선 + 1~2% 위에서 매수
```

### 되돌림 후 진입 (Retest)

```
시점: 돌파 후 3~7일 내 이전 저항선(이제 지지)으로 되돌림

장점: 더 낮은 진입가, 가짜 돌파 필터링
단점: 기회를 놓칠 수 있음

조건:
1. 돌파 후 이전 저항선으로 되돌림
2. 되돌림 시 거래량 감소 (건강한 조정)
3. 이전 저항선에서 반등 캔들 확인

진입: 되돌림 반등 첫날 시가 또는 종가
```

## 거래량 분석 (Volume Analysis)

돌파 전략에서 거래량은 진위를 판별하는 핵심 도구다:

```
진짜 돌파 신호:
- 돌파 당일: 평균 거래량 × 1.5~3배
- 돌파 후 3일: 평균 이상 유지

가짜 돌파 신호:
- 거래량 평균 이하로 돌파
- 돌파 당일만 거래량 급증, 이후 급감
- 장중 고점 형성 후 종가가 저항선 아래

On-Balance Volume (OBV):
- OBV가 신고가를 선행하면 강한 수요
- OBV가 하락하는데 가격만 오르면 약한 돌파
```

## 손절 및 목표 설정

### 손절

```
즉시 진입 손절:
- 돌파 레벨 아래 -3~-5%
- 또는 진입가 대비 -7% (CANSLIM 원칙)

되돌림 진입 손절:
- 이전 저항선(지지) 아래 -3%
- 박스권 중심 이하로 복귀 시

가짜 돌파 손절 (최우선):
- 종가가 돌파 레벨 아래로 복귀 시 즉시 청산
```

### 목표 설정

```
방법 1: 박스 높이 투영
목표 = 돌파 레벨 + 박스 높이

방법 2: 피보나치 연장
이전 상승폭의 161.8% 연장

방법 3: 다음 주요 저항
차트에서 다음 수평 저항 레벨

이익 실현:
- 1차 목표: 50% 청산
- 2차 목표: 30% 청산
- 나머지 20%: 트레일링 스탑으로 관리
```

## 코인 시장 돌파 전략

### BTC ATH 돌파

```
역사적 가장 강력한 신호:
- BTC가 이전 ATH 돌파 시
- 심리적 저항 없음 (모든 보유자 수익 상태)
- 기관 FOMO 매수 증가

BTC ATH 돌파 후 전략:
1. BTC ATH 돌파 확인 (주봉 종가 기준)
2. 알트코인 섹터 로테이션 시작
3. BTC.D 하락 전환 확인 시 알트 비중 증가

역사적 ATH 돌파 후 수익률:
2013: +500% (6개월)
2017: +300% (3개월)
2020: +400% (4개월)
```

### 알트코인 박스 돌파

```
알트 박스 돌파 조건:
1. BTC가 상승 추세 (BTC > 200일선)
2. 알트가 4~8주 박스권 형성
3. 박스 상단 돌파 + 거래량 급증
4. 섹터 내 다른 코인들도 강세

주의:
- BTC 하락 시 알트 돌파는 실패 확률 높음
- 알트는 BTC 대비 수익률로도 확인 (BTC 대비 강세인지)
- 거래량: 코인은 CEX 거래량 + DEX 거래량 합산

가짜 돌파 대처:
- 종가 기준 24시간 후 재확인
- 손절 -5~-8% (알트 변동성 감안)
```

### 핵심 가격 레벨

```
코인 시장 중요 심리적 레벨:
- 정수 (BTC: $50K, $100K, $200K)
- 이전 ATH
- 이전 사이클 저점
- 반감기 전후 가격

이 레벨들에서의 돌파는 더욱 강력한 모멘텀 유발
```

## 실전 체크리스트

```
진입 전:
[ ] 저항선 명확히 표시 (적어도 2회 이상 거절된 레벨)
[ ] 손절가 미리 계산 및 설정
[ ] 목표가 미리 설정 (최소 리스크/리워드 1:2)
[ ] 거래량 확인 (평균 대비 150% 이상)
[ ] 시장 전체 방향 확인 (나스닥/BTC 추세)
[ ] 포지션 크기 계산 (손절까지 1~2% 리스크)

진입 후:
[ ] 손절 주문 즉시 입력
[ ] 목표가 부분 청산 주문 예약
[ ] 가짜 돌파 신호 모니터링 (3일간)
[ ] 트레일링 스탑 계획 수립
```

## 핵심 교훈 요약

1. **거래량이 없는 돌파는 신뢰하지 마라** — 가짜 돌파의 가장 강력한 신호
2. **종가 기준으로 판단** — 장중 돌파는 기만적일 수 있음
3. **되돌림은 기회** — 돌파 후 리테스트가 더 안전한 진입
4. **박스권 기간이 길수록 돌파가 강하다** — 압축 에너지 원리
5. **손절은 돌파 레벨 바로 아래** — 돌파가 무효화된 즉시 청산
