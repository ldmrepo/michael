# 모멘텀 전략 (Momentum)

## 핵심 원리

> "오르는 것은 계속 오르고, 내리는 것은 계속 내린다."

모멘텀 전략은 최근 가장 많이 오른 자산을 매수하고 가장 많이 내린 자산을 공매도하는 전략이다. 학술적으로도 검증된 팩터 중 하나로, 주식 시장에서 가장 강력한 이상 현상 중 하나다.

---

## 절대 모멘텀 vs 상대 모멘텀

### 절대 모멘텀 (Absolute Momentum)

```
정의: 자산 자체의 최근 수익률 확인
기간: 12개월 (1개월 제외)

계산:
12개월 전 가격 대비 현재 가격 수익률
양수 → 매수 보유
음수 → 현금 또는 채권으로 전환

예시:
BTC 12개월 전 $30,000, 현재 $65,000
수익률 = +116.7% → 양수 → 매수 유지

BTC 12개월 전 $65,000, 현재 $40,000
수익률 = -38.5% → 음수 → 현금 전환
```

### 상대 모멘텀 (Relative Momentum)

```
정의: 여러 자산 중 상대적으로 강한 자산 선택
기간: 1, 3, 6, 12개월 복합

방법:
1. 투자 후보군 정의 (예: 상위 100개 코인)
2. 각 자산의 12개월 수익률 계산
3. 상위 10~20%만 매수
4. 하위 10~20%는 공매도 (또는 제외)
5. 매월 또는 분기별 리밸런싱
```

## 듀얼 모멘텀 전략 (Gary Antonacci)

가장 검증된 모멘텀 시스템 중 하나:

```
Step 1: 상대 모멘텀 — 주식 vs 채권 중 강한 것 선택
Step 2: 절대 모멘텀 — 선택된 자산이 양수 수익률인지 확인

결과:
둘 다 양수 → 강한 자산 매수
절대 모멘텀 음수 → 현금 (T-bill)

코인 버전:
BTC vs ETH vs 알트 → 상대 강도 1위 선택
→ 1위의 절대 모멘텀 양수 시 매수
→ 음수 시 스테이블코인 대기
```

## RS Rating (상대 강도 지수)

IBD(Investor's Business Daily) 방식의 상대 강도:

```
RS Rating 계산:
- 최근 12개월 수익률 (가중치 40%)
- 최근 6개월 수익률 (가중치 20%)
- 최근 3개월 수익률 (가중치 20%)
- 최근 1개월 수익률 (가중치 20%)

해석:
RS 99: 시장 내 상위 1%
RS 80+: 매수 고려 (상위 20%)
RS 50~: 시장 평균
RS 20-: 약한 종목 (제외)

O'Neil 법칙: RS 80+ 종목만 매수 고려
```

## 모멘텀 진입 전략

### 52주 신고가 돌파 모멘텀

```
조건:
1. 52주 신고가 돌파
2. 거래량 평균 대비 +50% 이상
3. 시장 환경 양호 (S&P500 > 200일선)
4. RS Rating > 85

진입:
- 신고가 돌파 당일 또는 다음날 장 초반
- 돌파점 + 0.5~1% 라인 매수
- 포지션: 계좌의 10~15%

손절:
- 돌파점 아래 -7% 이탈 시
```

### 눌림목 모멘텀 (Pullback Momentum)

```
조건:
1. 강한 상승 추세 (최근 3개월 +30% 이상)
2. 10~15% 눌림목 발생
3. 거래량 감소하며 눌림목 (건강한 조정)
4. 20일 이평선 또는 주요 지지선 근처

진입:
- 눌림목에서 지지 확인 후 반등 시
- 반등 첫날 거래량 증가 확인

손절:
- 눌림목 저점 아래 -3%
```

## 모멘텀 청산

### 모멘텀 소멸 신호

```
1. RS Rating 급락 (10점 이상 하락)
2. 52주 고점 대비 -20% 이탈
3. 섹터 내 다른 리더 종목들 하락 전환
4. 시장 전체 분배 패턴 (Distribution Days 증가)
5. 절대 모멘텀 음수 전환 (12개월 수익률 마이너스)
```

### 포지션 교체

```
월별 리밸런싱:
1. 현재 보유 자산의 RS Rating 재계산
2. RS Rating 하위 20% 탈락 → 매도
3. 새로운 RS Rating 상위 20% → 매수
4. 교체 비율: 전체의 20~30%
```

## 코인 모멘텀 전략

### BTC 사이클 모멘텀

```
BTC 12개월 모멘텀:
- 반감기 후 12~18개월: 양수 모멘텀 (매수)
- ATH 이후 하락 초기: 음수 전환 (매도/현금)

역사적 패턴:
2012 반감기 → 2013 bull run (+5,000%)
2016 반감기 → 2017 bull run (+2,000%)
2020 반감기 → 2021 bull run (+700%)
2024 반감기 → 2025~2026 예상 상승
```

### 알트코인 상대 모멘텀

```
알트 시즌 포착:
1. BTC.D (비트코인 도미넌스) 하락 전환
2. ETH/BTC 비율 상승
3. 알트 전체 시총 증가율 > BTC 증가율

상대 모멘텀 Top 10 알트 선택:
- 최근 1개월 BTC 대비 초과 성과
- 최근 3개월 BTC 대비 초과 성과
- 두 기간 모두 양수 알트만 선택
- 주간 리밸런싱

포지션 관리:
- 상위 5개 알트 각 5~10%
- BTC < 200일선 시 알트 전량 청산
```

## 모멘텀 전략의 위험

```
모멘텀 크래시 (Momentum Crash):
- 시장 급반전 시 모멘텀 주식이 더 크게 하락
- 2009년, 2020년 등 급반전 시 -30~-50%

대응:
- 시장 절대 모멘텀 음수 시 현금 전환 (핵심 방어)
- 포지션 집중도 낮게 유지 (분산)
- 큰 뉴스 이벤트 전 포지션 축소
```

## 2024~2025 코인 실전 사례

### Case 1: SUI 상대 모멘텀 전략 (2024 Q3~Q4)

```
배경: SUI $0.50 → 2024년 7월부터 BTC 대비 초과 성과 시작
RS Rating: 상위 5% (12개월 수익률 +800%)
진입: $1.20 (2024년 9월, 52주 신고가 돌파 + 거래량 300%)
피라미딩: $2.50 (눌림목 반등, BTC 대비 강도 유지)
청산: $4.80 (2025년 1월, RS Rating 둔화 + BTC.D 반등)
수익: +300% (4개월)
핵심: Move 생태계 내러티브 + 실사용 증가 → 모멘텀 지속
```

### Case 2: VIRTUAL (AI 에이전트) 모멘텀 급등과 크래시 (2024 Q4)

```
배경: AI 에이전트 내러티브로 VIRTUAL $0.02 → $5.20 (+26,000%)
진입 적기: $0.50 (RS Rating 99, CT 언급 급증, 2024년 10월)
과열 신호: 파생 토큰 수백개 런칭, 모든 KOL 추천 (2025년 1월)
결과: $5.20 → $0.80 (-85%, 2개월)
교훈: 모멘텀 크래시의 전형적 사례
      → 모멘텀 소멸 신호(대중화 + 파생 범람) 감지 시 즉시 청산
      → 절대 모멘텀 음수 전환 확인 후 현금 전환이 핵심 방어
```

### Case 3: 듀얼 모멘텀으로 BTC vs ETH 선택 (2025 Q1)

```
배경: 2025년 1~3월, BTC $95K 횡보 vs ETH $3,400 → $1,900 급락
상대 모멘텀: BTC 12개월 +95%, ETH 12개월 -15%
절대 모멘텀: BTC 양수, ETH 음수
듀얼 모멘텀 결론: BTC 100% (ETH 배제)
결과: BTC 횡보(-5%) vs ETH -44% → ETH 회피로 대규모 손실 방지
핵심: 듀얼 모멘텀이 "ETH는 이번엔 다르다" 감정을 차단
```

## 핵심 교훈 요약

1. **강한 것은 더 강해진다** — 모멘텀은 단기적으로 지속된다
2. **시장 전체 모멘텀이 음수면 현금** — 절대 모멘텀이 방어막
3. **RS 80+ 종목만** — 평균 이하 종목에서 반등을 기대하지 마라
4. **월별 리밸런싱** — 모멘텀은 정기적 교체가 필요
5. **모멘텀 크래시 대비** — 시장 급변 시 손실 클 수 있음
