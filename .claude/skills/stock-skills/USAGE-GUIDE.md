# Stock Skills 사용 가이드

**버전**: 2.0 | **최종 업데이트**: 2026-03-07

---

## 개요

`stock-skills`는 주식 트레이딩 대가들의 전략을 암호화폐 시장에 적용한 **마이클 AI 전용 트레이딩 지식 라이브러리**입니다.
마이클에게 트레이딩 관련 질문을 하면 이 라이브러리를 자동으로 참조하여 전략을 제시합니다.

## 상황별 사용 시나리오

### 시나리오 1: "지금 뭐 사야 해?"

**→ followalong-strategy.md 참조**

```
마이클에게: "지금 코인 투자 전략 알려줘"

마이클이 제공하는 것:
1. 매크로 체크리스트 (드러켄밀러식)
2. 포트폴리오 템플릿 (보수/중립/공격형)
3. 진입→청산 7단계 플로우차트
4. 주간 모니터링 체크리스트
```

---

### 시나리오 2: "XRP 언제 추가 매수해?"

**→ mean-reversion.md + livermore.md 참조**

```
마이클에게: "XRP 박스권 평균 회귀 전략 적용해줘"

마이클이 제공하는 것:
- 볼린저 하단 + RSI < 30 진입 조건
- 분할 매수 50% + 50% 구조
- 리버모어 피라미딩: $1.47 돌파 시 추가 레벨
- 손절: Exchange SL $1.3413 유지
```

### 시나리오 5: "리스크 관리 방법은?"

**→ tudor-jones.md 참조**

마이클이 제공하는 것:

## 자주 묻는 질문

**Q: 이 전략들이 항상 맞나요?**
A: 아닙니다. 모든 전략은 확률 기반이며, 손절 원칙이 수익보다 중요합니다. 튜더 존스의 1% 리스크 룰을 반드시 지키세요.

**Q: 알트코인과 BTC 중 어디에 집중해야 하나요?**
A: BTC 도미넌스를 기준으로 판단하세요. > 60%면 BTC 중심, < 50%면 알트 비중 확대. (altcoin-rotation.md 참조)

**Q: 얼마나 자주 체크해야 하나요?**
A: 주간 모니터링(월요일 7가지 체크) + 마이클 자동 알림 설정으로 충분합니다. 일봉 이하 단타는 12x 레버리지 시 권장하지 않습니다.

**Q: 손절 후 재진입은 어떻게 하나요?**
A: 3연속 손절 시 1일 거래 중단 → 시장 환경 재평가 → RSI < 30 + 볼린저 하단 조건 다시 확인 후 재진입.
