# 개인화 뉴스 브리핑 (News Briefing)

사용자의 관심 분야에 맞춘 뉴스를 수집하고 요약하여 전송합니다.

## 기능

1. **뉴스 수집**: Google News RSS, Naver 뉴스 API 활용
2. **개인화 필터링**: 사용자 관심 키워드 기반
3. **요약 생성**: 핵심 내용 3-5문장 요약
4. **스케줄 브리핑**: 매일 아침 자동 전송 가능

## 사용 방법

### 즉시 뉴스 요청
```
"오늘 뉴스 알려줘"
"AI 관련 뉴스"
"비트코인 소식"
"최신 헤드라인"
```

### 관심사 설정
```
"AI, 주식, 축구 뉴스 받고 싶어"
→ [FACT:news_interests:AI,주식,축구] 저장
```

### 아침 브리핑 스케줄 설정
```
"매일 아침 7시에 뉴스 브리핑 보내줘"
→ [SCHEDULE:0 7 * * *:아침 뉴스 브리핑을 전송합니다]
```

## 뉴스 수집 스크립트

뉴스 수집 시 다음 스크립트를 사용합니다:

```bash
bash scripts/news/fetch-news.sh "검색키워드" [개수]
```

### 예시
```bash
# AI 관련 뉴스 5개 수집
bash scripts/news/fetch-news.sh "AI" 5

# 비트코인 뉴스 3개 수집
bash scripts/news/fetch-news.sh "비트코인" 3
```

```

📰 오늘의 뉴스 브리핑

🤖 [카테고리1]

• [헤드라인2] - [요약]
```

```
📰 [키워드] 관련 최신 뉴스

   [요약 2-3문장]
   🔗 [출처]

2. [헤드라인]
   [요약 2-3문장]
   🔗 [출처]
```

## 데이터 소스

1. **Google News RSS** (기본)
   - 무료, 키워드 검색 가능
   - 한국어 지원 (hl=ko&gl=KR)

2. **Naver 뉴스 검색 API** (선택)
   - 무료 25,000회/일
   - 한국 뉴스 특화

## 워크플로우

1. 사용자 관심사 확인 (메모리에서 `news_interests` fact 조회)
2. 관심사별 뉴스 수집 (fetch-news.sh 호출)
3. 중복 제거 및 최신순 정렬
4. Claude가 요약 생성
5. 포맷팅 후 전송

## 관심사 저장 형식

메모리에 저장되는 관심사:
```
[FACT:news_interests:AI,비트코인,주식,축구]
```

쉼표로 구분된 키워드 목록

## 예시 대화

```
User: "뉴스 브리핑 설정하고 싶어"
Michael: 어떤 분야의 뉴스를 받아보고 싶으세요?
         예: AI, 주식, 암호화폐, 스포츠, 연예 등

User: "AI랑 비트코인"
Michael: [FACT:news_interests:AI,비트코인]
         ✅ 관심 분야를 AI, 비트코인으로 설정했습니다.

         매일 아침 브리핑을 받으시겠어요?

User: "응, 아침 8시에"
Michael: [SCHEDULE:0 8 * * *:아침 뉴스 브리핑 전송]
         ✅ 매일 오전 8시에 뉴스 브리핑을 보내드리겠습니다!
```
