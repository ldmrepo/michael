# DCA Strategist (DCA 전략가) — Foundational Knowledge

## 역할 정의

DCA 전략가는 **정기적 분할 매수 전략을 설계하고 최적화**하는 전문 에이전트다. 단순히 "매주 $100 BTC 매수"를 넘어, 시장 상황·변동성·자산 특성에 따라 **매수 빈도, 금액, 자산 배분을 동적으로 조정**하는 것이 핵심이다.

DCA의 본질적 가치는 **시장 타이밍 제거**다. 인간(그리고 AI조차)은 일관되게 시장 바닥을 맞출 수 없다. DCA는 이 현실을 인정하고, 시간 분산을 통해 평균 매입 단가를 안정화한다. 전략가의 역할은 이 기본 원칙 위에서 실행 효율을 극대화하는 것이다.

## 핵심 개념

### 1. DCA vs Lump Sum — 데이터 기반 비교

**전통 시장 연구 (Vanguard, 2012)**:
- 미국/영국/호주 주식: Lump sum이 **66%의 경우** DCA보다 우수
- 이유: 시장은 장기적으로 우상향하므로 일찍 투자할수록 유리

**크립토 시장 실증 데이터**:

| 분석 기간 | DCA 수익 | Lump Sum 수익 | 승자 |
|---|---|---|---|
| 2019-2024 BTC ($10/주) | +202% ($2,620→$7,913) | 시기 의존 | DCA (긴 기간 평균) |
| 2021.4-2024 BTC (연간 투자) | +106% | +154% (DCA) | DCA 우세 |
| 2017 ATH Lump Sum | -84% (1,227일 회복) | N/A | DCA 압도적 우세 |
| 2020.3 저점 Lump Sum | +1,500%+ | N/A | Lump Sum 압도적 우세 |

**핵심 결론**:
- Lump sum은 **수학적으로 66% 확률로 우세**하나, 크립토의 극단적 변동성에서는 DCA의 **리스크 조정 수익(risk-adjusted return)**이 더 안정적
- 2018 크립토 겨울(-84%, 24개월): DCA가 저가 매수 기회를 자동 포착하여 회복기에 Lump sum 대비 유리
- **BTC 최고의 15개 3일 상승을 놓치면**: +127% 수익 → -84.6% 손실. DCA는 이 리스크를 자연 분산

**실전 가이드라인**:
```
보유 자금 전액 투자 가능한 상황:
  시장이 ATH 대비 -50% 이상 하락? → Lump Sum 유리 (역사적 저점 근처)
  시장이 ATH 근처 또는 신고가? → DCA 강력 권장 (하방 리스크 큼)
  판단 불가? → DCA (기본 전략)

정기 수입으로 투자:
  → 무조건 DCA (자금이 순차적으로 유입되므로 선택의 여지 없음)
```

### 2. DCA 빈도 최적화 (Frequency Optimization)

**빈도별 특성 비교**:

| 빈도 | 장점 | 단점 | 추천 상황 |
|---|---|---|---|
| **일간** | 최대 평균화 효과, 변동성 포착 극대화 | 수수료 누적, API 호출 빈번 | 고변동성 자산 (알트코인), 소액 |
| **주간** | 수수료/효과 균형, 관리 용이 | 주간 내 큰 변동 놓칠 수 있음 | **BTC/ETH 기본 전략 (권장)** |
| **격주** | 수수료 절감 | 평균화 효과 감소 | 중간 금액 |
| **월간** | 최소 수수료, 최소 관리 | 월 내 변동 미포착 | 대형 자산, $1,000+/월 |

**수수료 영향 분석**:
```
Binance Spot: 0.075% (BNB 할인 적용)
$100/주 DCA (52회/년): 수수료 = $100 × 0.075% × 52 = $3.90/년
$400/월 DCA (12회/년): 수수료 = $400 × 0.075% × 12 = $3.60/년
→ 차이: $0.30/년 (무시 가능)

BUT 최소 주문 금액 제약:
BTC 최소: ~$5 (minNotional)
알트코인: $10-20
→ 일간 DCA는 최소 $10-20/일 = $300-600/월 필요
```

**크립토 특화 빈도 결정 공식**:
```
최적 빈도 = f(투자금액, 수수료율, 자산 변동성)

변동성 > 5% 일간: 일간 또는 주간 (변동성 포착 가치 > 수수료)
변동성 2-5% 일간: 주간 (기본)
변동성 < 2% 일간: 격주 또는 월간 (평균화 효과 미미)
```

### 3. Enhanced DCA 변형

**Standard DCA (정액 분할 매수)**:
- 매 주기 동일 금액 투자
- 가격 높을 때 적게, 낮을 때 많이 매수 (자동 평균화)
- 최대 장점: 단순성. 판단 불필요

**Value Averaging (가치 평균법)**:
- 목표: 포트폴리오 가치가 매 주기 일정 금액만큼 증가하도록 투자
- 가격 하락 시 더 많이 매수, 상승 시 적게 매수 (또는 매도)
- 공식:
```
이번 투자금 = 목표 가치 - 현재 포트폴리오 가치
목표 가치 = 기본 투자액 × 경과 주기 수

예시 (월 $500 목표 증가):
  3개월차 목표: $1,500
  현재 가치: $1,200 (가격 하락)
  이번 투자: $300 (추가 매수)

  현재 가치: $1,700 (가격 상승)
  이번 투자: -$200 (일부 매도 또는 스킵)
```
- **장점**: DCA보다 낮은 평균 단가 달성 가능 (역사적으로 0.5~1% 개선)
- **단점**: 하락장에서 투자 금액 증가 → 자금 소진 위험. 상승장에서 매도 발생 → 세금 이벤트

**Momentum DCA (모멘텀 기반)**:
- 가격 추세에 따라 투자 금액 조정
- 상승 추세: 기본 금액의 70~80% (이미 비싼 가격)
- 하락 추세: 기본 금액의 120~150% (할인 매수)
- 횡보: 기본 금액 100%

```
추세 판단 기준:
  현재가 > 50일 이동평균: 상승 추세
  현재가 < 50일 이동평균: 하락 추세
  |현재가 - 50일MA| / 50일MA < 3%: 횡보
```

**Volatility-Weighted DCA (변동성 가중)**:
- 변동성이 높을 때 더 많이 투자 (더 넓은 가격 범위에서 매수)
- 변동성이 낮을 때 적게 투자
- 직관에 반하지만 수학적으로 유리: 변동성 높은 시기에 저가 매수 기회가 더 많음

```
변동성 가중 계수 = 현재 30일 변동성 / 장기 평균 변동성
투자금 = 기본금액 × min(변동성 가중 계수, 2.0)  # 최대 2배 cap

예시:
  BTC 장기 평균 변동성: 60% (연간)
  현재 30일 변동성: 90%
  계수: 90/60 = 1.5
  기본 $100 → 이번 주기 $150
```

### 4. 시장 국면별 DCA 전략

**Bull Market (상승장)**:
- 표준 DCA 유지. 금액 축소하지 않음
- FOMO 방지: DCA 금액 이상 추가 투입 자제
- 이익 실현 DCA: 목표가 도달 시 역 DCA로 일부 매도 시작

**Bear Market (하락장)**:
- DCA 금액 유지 또는 증가 (Value Averaging 적용)
- 심리적 압박 최대. **자동화가 핵심** (수동이면 중단 유혹)
- 2018-2019 BTC 겨울: DCA 지속한 투자자는 2020-2021 불마켓에서 3-5배 수익

**Sideways (횡보장)**:
- 표준 DCA 유지
- 변동성 낮으면 빈도 축소 고려 (주간→격주)
- 축적 기회: 레인지 하단에서 모멘텀 DCA로 약간 증가

**Capitulation (패닉 매도장)**:
- DCA 금액 최대 증가 (기본의 2배까지)
- 역사적으로 최고의 매수 시점
- VIX(주식) 또는 Crypto Fear & Greed Index 10-15 수준: 극도의 공포 = 극도의 기회
- **주의**: "떨어지는 칼" 리스크 존재. 금액 증가하되 all-in은 금지

### 5. 자산 선택 기준

**DCA에 적합한 자산**:
- 장기 우상향 확신: BTC, ETH (10년 이상 트랙 레코드)
- 높은 변동성: 평균화 효과 극대화
- 충분한 유동성: 소량 주문이 슬리피지 없이 체결

**DCA에 부적합한 자산**:
- 장기 하락 추세 (구조적 쇠퇴 중인 알트코인)
- 유동성 극히 낮은 자산 (소형 알트코인)
- 단기 이벤트 기반 자산 (예측 마켓 토큰 등)

**자산별 권장 DCA 구성**:

| 자산 | 비중 | DCA 빈도 | 근거 |
|---|---|---|---|
| BTC | 50-60% | 주간 | 장기 안정성, 기관 채택 |
| ETH | 20-30% | 주간 | 스마트 컨트랙트 생태계 |
| SOL/대형 알트 | 10-15% | 격주 | 성장 잠재력, 위험 분산 |
| 스테이블코인 (현금) | 5-10% | N/A | 기회 자금, 리밸런싱 버퍼 |

## 베스트 프랙티스

### DCA 설정 체크리스트

1. **투자 목표 정의**: 자산 축적 (적립) vs 목표 금액 도달 vs 포트폴리오 구축
2. **총 예산 확정**: 월 투자 가능 금액 (생활비 제외 여유 자금만)
3. **자산 선택**: 위 자산별 권장 비중 참조
4. **빈도 결정**: 기본 주간, 변동성에 따라 조정
5. **DCA 변형 선택**: Standard (기본), Value Averaging (경험자), Momentum (고급)
6. **자동화 설정**: 수동 실행 시 심리적 이탈 확률 70%+

### Accumulation vs Distribution

**축적 단계 (Accumulation Phase)**:
- 목표: 포지션 구축. 평균 단가 최소화
- DCA 금액: 일정 또는 Value Averaging
- 기간: 6개월~2년+
- **중단 금지**: 하락장에서 DCA 중단은 최악의 판단

**분배 단계 (Distribution Phase)**:
- 목표: 이익 실현. 매도 타이밍 분산
- 역 DCA: 정기적으로 일정 비율/금액 매도
- 기간: 포트폴리오 목표 도달 후

```
역 DCA 예시:
  BTC 1.0개 보유, 목표 이익 실현
  매주 0.05 BTC 매도 (20주에 걸쳐 전량 매도)
  → 매도 가격 평균화, 최고점 놓침 리스크 감소
```

### 리밸런싱과의 연계

DCA와 포트폴리오 리밸런싱은 상호 보완적:
- DCA 매수 시 가중치가 가장 낮은 자산 우선 매수 → 자연스러운 리밸런싱
- 월 1회 비중 검토, DCA 금액 비율 조정

```
목표: BTC 60%, ETH 30%, SOL 10%
현재: BTC 55%, ETH 35%, SOL 10%

이번 주 DCA $200:
  BTC: $200 × (60% - 55% 보정) = $120 (60% + 추가)
  ETH: $200 × (30% - 35% 보정) = $60 (30% - 감소)
  SOL: $200 × 10% = $20 (정상)
```

## 주의사항 / 안티패턴

### 절대 하지 말 것

1. **감정 기반 DCA 중단**: "이번에는 너무 비싸서 스킵" → DCA 원칙 파괴. 자동화 필수
2. **하락장에서 DCA 금액 감소**: 역으로 증가시켜야 함 (저가 매수 기회)
3. **All-in 유혹**: "바닥이니까 DCA 대신 전액 투자" → 바닥 확인은 사후에만 가능
4. **고빈도 DCA에 고수수료 거래소 사용**: 일간 DCA에 수수료 0.5%면 연 130% 수수료
5. **DCA 자산을 자주 교체**: 3개월마다 다른 알트코인으로 변경 → 분산 효과 상실
6. **생활비로 DCA**: 투자는 여유 자금만. 긴급 자금 고갈 시 DCA 강제 중단 + 불리한 시점에 매도

### 흔한 실수

- **수수료 미고려**: 일간 DCA $5 (연 $3.65 수수료, 투자금의 0.2%는 양호. 하지만 $1/일이면 수수료 비중 1%+)
- **세금 이벤트 무시**: 매수는 세금 없지만, Value Averaging에서 매도 발생 시 과세 대상
- **과도한 자산 분산**: 5개 이상 자산에 소액 DCA → 관리 비용 > 분산 효과
- **DCA 시작 시점 집착**: "더 떨어지면 시작하자" → 이미 DCA 원칙 위반 (타이밍 시도)
- **한 방향만 고려**: 축적 DCA만 설계하고 분배(출구) 전략 없음

## 판단 기준

### DCA 변형 선택 가이드

```
투자 경험 < 1년?
  → Standard DCA (가장 단순, 실수 최소)

투자 경험 1-3년 + 하락 내성 확인?
  → Momentum DCA (추세 활용)

투자 경험 3년+ + 자금 여유 충분?
  → Value Averaging (최적 평균 단가)

자동화 환경 완비?
  → Volatility-Weighted DCA (변동성 데이터 실시간 반영)
```

### DCA 빈도 결정 매트릭스

| 월 투자액 | BTC/ETH | 대형 알트 | 소형 알트 |
|---|---|---|---|
| < $200 | 월간 | 월간 | DCA 비추천 |
| $200-$500 | 격주 | 월간 | DCA 비추천 |
| $500-$2,000 | **주간 (권장)** | 격주 | 월간 |
| $2,000+ | 주간 또는 일간 | 주간 | 격주 |

### DCA 성과 모니터링 지표

| 지표 | 계산 | 건강한 범위 |
|---|---|---|
| 평균 매입 단가 | 총 투자금 / 총 수량 | 현재가 대비 -20%~+10% |
| 실현 평균화 효과 | (단순 평균가 - DCA 평균가) / 단순 평균가 | 양수 (2-8% 일반적) |
| 투자 일관성 | 실행 횟수 / 예정 횟수 | > 95% |
| 수수료 비율 | 총 수수료 / 총 투자금 | < 0.3% |

### 시장 국면 판단 기준

| 지표 | Bull | Sideways | Bear | Capitulation |
|---|---|---|---|---|
| BTC 200일 MA 대비 | +20% 이상 | +/-10% | -20% 이상 | -40% 이상 |
| Fear & Greed Index | 60-90 | 40-60 | 20-40 | 10-20 |
| 30일 변동성 (연환산) | 40-80% | 20-40% | 60-100% | 100%+ |
| DCA 금액 조정 | 기본 100% | 기본 100% | 120-150% | 150-200% |

### DCA 중단/재개 기준

**중단 절대 금지** (심리적 이유로 중단하면 안 됨)

**일시 정지 허용 조건**:
- 긴급 자금 필요 (생활비 부족)
- 자산 구조 변경 (DCA 대상 자산 재선택 중)
- 거래소 문제 (API 다운, 보안 사고)

**재개 규칙**:
- 정지 기간 중 미투자 금액을 3-6개월에 걸쳐 분산 투입
- 즉시 전액 투입하지 않음 (Mini Lump Sum 리스크)
