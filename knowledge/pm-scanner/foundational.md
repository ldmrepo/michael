# Prediction Market Scanner (예측시장 스캐너) — Foundational Knowledge

## 역할 정의

예측시장 스캐너는 Polymarket 등 예측 시장(prediction market)에서 **가격 비효율성(mispricing), 유동성 프리미엄, 만기 수렴(maturity convergence), 차익거래(arbitrage) 기회**를 탐지하는 에이전트다.

이 에이전트가 존재하는 이유: 예측 시장은 전통 금융보다 **훨씬 비효율적**이다. 2024-2025년 학술 연구에 따르면, Polymarket에서만 $40M 이상의 차익거래 수익이 추출되었다(86M 베팅, 수천 개 마켓 분석). Bid-ask 스프레드는 2025년 초 4.2센트에서 말에 2.4센트로 압축되었지만, 여전히 주식 시장 대비 10-100배 넓다. 이러한 비효율성은 **체계적 접근을 통해 수익을 창출**할 수 있는 기회를 제공한다.

Polymarket 트레이더의 0.51%만이 체계적으로 수익을 올린다. 우리의 목표는 이 0.51%에 들어가는 것이다.

## 핵심 개념

### 1. 예측 시장 효율성 이론 (EMH Applied to Prediction Markets)

효율적 시장 가설(EMH)에 따르면, 시장 가격은 모든 가용 정보를 반영해야 한다. 예측 시장에서 이는 **가격 = 확률**을 의미한다.

**현실에서의 비효율성 원인**:

| 비효율성 원인 | 설명 | 수익 기회 |
|:---|:---|:---|
| **유동성 부족** | 거래량 적은 마켓은 정보 반영이 느림 | 정보 우위 활용 |
| **감정적 편향** | 스포츠, 정치 마켓에서 팬 바이어스 | 팬 기반 편향 역발상 |
| **소수 참여자** | Polymarket 기준 3-4개 대형 마켓 메이커 | 마켓 메이킹 스프레드 수익 |
| **복잡한 마켓 구조** | 다중 결과(multi-outcome) 마켓 확률 합 ≠ 100% | 확률 불일치 차익 |
| **정보 시차** | 뉴스 반영까지 수분-수시간 | 빠른 정보 반영 |
| **만기 효과** | 만기 근접 시 급격한 가격 수렴 | 만기 전략 |

**효율성 등급 (카테고리별, 2025년 연구)**:

| 카테고리 | 효율성 | 스프레드 | 기회 |
|:---|:---|:---|:---|
| **금융/경제** | 높음 | 1-2센트 | 적음. 기관 참여 활발. |
| **정치** | 중간-높음 | 2-3센트 | 선거 시즌 외엔 제한적 |
| **스포츠** | 낮음 | 3-5센트 | 팬 바이어스 활용 가능 |
| **엔터테인먼트** | 낮음 | 4-8센트 | 감정적 베팅 + 낮은 유동성 |
| **과학/기술** | 낮음 | 5-10센트 | 전문가 지식 우위 활용 가능 |
| **암호화폐** | 중간 | 2-4센트 | 온체인 데이터 활용 가능 |

### 2. 유동성 프리미엄 분석 (Liquidity Premium Analysis)

유동성이 낮은 마켓은 체계적으로 **비효율적 가격**을 보인다.

**유동성 프리미엄**: 유동성이 부족한 마켓에서 마켓 메이커가 요구하는 추가 스프레드.

| 일일 거래량 | 예상 스프레드 | 유동성 프리미엄 | 전략 |
|:---|:---|:---|:---|
| $1M+ | 1-2센트 | 0-1센트 | 스프레드 작음. 방향성 베팅만 유효. |
| $100K-$1M | 2-4센트 | 1-3센트 | 중간 기회. 시장 양면 참여 가능. |
| $10K-$100K | 4-8센트 | 3-7센트 | 높은 스프레드. 마켓 메이킹 수익성 높음. |
| $10K 미만 | 8-20센트 | 7-19센트 | 매우 높은 스프레드. 유동성 리스크 주의. |

**Polymarket Liquidity Rewards**: Q-score 기반 일일 USDC 보상 시스템.
- Q-score = f(스프레드 타이트니스, 주문 깊이, 지속적 활동)
- 2025년 총 보상: $12M+
- **마켓 메이킹 + 예측** 결합이 최적 전략
- 신규 마켓의 연환산 수익률: 80-200% (초기 유동성 부족 활용)

### 3. 만기 수렴 (Maturity Convergence)

**원칙**: 만기(결과 확정일)가 가까워질수록 가격은 0 또는 1로 수렴한다.

**수렴 속도 패턴**:

```
가격
1.0 |     확실한 YES ───────────────────── 1.00
    |                        ╱
0.9 |                   ╱───╱
    |              ╱───╱
0.7 |         ╱───╱
    |    ╱───╱
0.5 |───╱     ← 불확실 구간
    |    ╲───╲
0.3 |         ╲───╲
    |              ╲───╲
0.1 |                   ╲───╲
    |                        ╲
0.0 |     확실한 NO ───────────────────── 0.00
    └──────────────────────────────────────
    생성일                           만기일
```

**만기 기반 전략**:

| 만기까지 잔여 | 가격 범위 | 전략 |
|:---|:---|:---|
| 30일+ | 0.20-0.80 | 정보 기반 방향성 베팅. 변동성 높음. |
| 7-30일 | 0.10-0.90 또는 0.05-0.15/0.85-0.95 | 수렴 베팅. 방향 확신 있으면 고확률 포지션. |
| 1-7일 | 대부분 0.05 이하 또는 0.95 이상 | 만기 임박 고확률 수확. 0.95 매수 → 1.00 정산 = 5% 수익/1주. |
| 24시간 내 | 0.01 이하 또는 0.99 이상 | 거의 확정. 잔여 위험 대비 수익 미미. |

**만기 스프레드 전략**: 같은 이벤트의 서로 다른 만기 마켓 간 가격 차이 활용. 예: "BTC $100K by March" 0.60 vs "BTC $100K by June" 0.75 → 3개월 추가 시간에 대해 15센트 프리미엄.

### 4. 이진 vs 다중 결과 마켓 (Binary vs Multi-Outcome Markets)

#### 이진 마켓 (Binary)

- **구조**: YES/NO 두 가지 결과. YES + NO = $1.00
- **특징**: 가장 단순. 유동성 집중. 가격 = 확률로 직관적 해석 가능.
- **비효율성 체크**: YES + NO < $1.00이면 **차익거래 기회**. YES + NO > $1.00이면 누군가 과대 지불.

#### 다중 결과 마켓 (Multi-Outcome)

- **구조**: 3개 이상의 결과. 모든 결과의 가격 합 = $1.00이어야 정상.
- **비효율성 빈도**: 이진 마켓보다 훨씬 높음. 합이 $1.00에서 벗어나는 경우 빈번.
- **over-round**: 모든 결과 가격 합 > $1.00. 마켓 메이커의 마진. 주식 시장의 vigorish와 유사.

**다중 결과 마켓 비효율 예시**:
```
미국 대통령 선거:
  후보 A: $0.45
  후보 B: $0.42
  후보 C: $0.08
  기타:   $0.10
  ───────────
  합계:   $1.05 → 5센트 over-round = 마켓 메이커 마진
```

$1.05에서 모든 결과를 1개씩 매수하면 어떤 결과가 나오든 $1.00 수령 → $0.05 손실. 반대로, 합이 $0.95이면 모든 결과 매수 → $0.05 무위험 수익.

### 5. Polymarket 특화 패턴 (Polymarket-Specific Patterns)

#### CLOB (Central Limit Order Book) 구조

Polymarket은 AMM이 아닌 **CLOB** 기반. 전통 주식 거래소와 유사한 주문장.

**핵심 특성**:
- **수수료**: Maker 0% (리베이트 있음), Taker 최대 3% (마켓별 상이)
- **최소 가격 단위**: $0.01 (1센트)
- **결제**: USDC.e on Polygon
- **정산**: CTF (Conditional Token Framework) 기반. 결과 확정 시 자동 정산.

#### 가격 이상 패턴

| 패턴 | 설명 | 원인 | 대응 |
|:---|:---|:---|:---|
| **Penny Stock Spike** | 0.01-0.05에서 갑작스러운 급등 | 뉴스 또는 투기적 매수 | 유동성 확인 후 참여 여부 판단 |
| **0.99 Stuck** | 거의 확실한 결과인데 0.99에 고착 | 만기 불확실성 프리미엄 | 0.99 매수 → 정산 시 1센트 이익 (연환산 높음) |
| **Event Cliff** | 이벤트 직전/직후 급격한 가격 변동 | 정보 비대칭 해소 | 이벤트 직전 스프레드 확대 주의 |
| **Volume Spike + No Price Move** | 거래량 폭증이나 가격 변화 없음 | 양방향 매수/매도 균형 | 대형 참여자 진입 신호. 향후 방향 변화 관찰 |
| **Correlated Market Divergence** | 관련 마켓 간 비논리적 가격 차이 | 마켓 간 정보 전파 지연 | 차익거래 기회 |

#### Polymarket 시간대별 활동 패턴

- **미국 거래 시간(13:30-21:00 UTC)**: 최대 유동성. 스프레드 최소. 뉴스 반응 가장 빠름.
- **아시아 시간(00:00-08:00 UTC)**: 유동성 40-60% 감소. 스프레드 확대. 대형 주문에 취약.
- **주말**: 유동성 추가 30% 감소. 스포츠 마켓 제외.

### 6. VWAP와 마켓 메이커 행동 (Volume-Weighted Average Price)

**VWAP**: 거래량 가중 평균 가격. 대량 거래의 실행 품질을 평가하는 기준.

**마켓 메이커 전략 관찰**:
- 스프레드 양쪽에 동시 주문 → 중간 스프레드(mid-spread)가 마켓 메이커의 "공정 가격" 추정
- 한쪽 주문이 사라지거나 크기가 줄면 → 마켓 메이커가 방향성 전환
- 스프레드가 갑자기 넓어지면 → 뉴스 이벤트 예상 또는 유동성 철수

**마켓 메이커 수**:
- 2025년 기준: 주요 마켓 메이커 3-4개. 대부분 수동 운영.
- 마켓 메이커 부재(주말, 변동성 이벤트) 시 스프레드 5-10배 확대

### 7. 차익거래 유형 (Arbitrage Types)

#### Type 1: 마켓 리밸런싱 차익거래 (Single Market)

같은 마켓 내에서 YES + NO < $1.00인 경우.

**예시**: BTC $100K by March — YES: $0.48, NO: $0.48 → 합계 $0.96
- 양쪽 모두 매수: $0.96 투입 → 어떤 결과든 $1.00 수령 → $0.04 무위험 수익 (4.2% 수익률)

**발생 빈도**: 2024-2025년 기준 일일 수십 건. 대부분 $0.01-$0.02 수준의 소규모.

#### Type 2: 결합 차익거래 (Combinatorial)

여러 마켓 간 논리적 불일치를 활용.

**예시**:
- "BTC $100K by June" YES: $0.75
- "BTC $80K by June" YES: $0.90
- BTC가 $100K 이상이면 당연히 $80K 이상 → 두 번째 마켓이 더 비싸야 함 (✓)
- 만약 "BTC $80K by June" YES가 $0.70이면? → 논리적 모순 → 차익 기회

#### Type 3: 크로스 플랫폼 차익거래

Polymarket vs Kalshi vs PredictIt 간 같은 이벤트 다른 가격.

**실전 난이도**: 높음. 플랫폼 간 정산 시간, 수수료, 자금 이동 비용 고려 필요.

**2024-2025년 실적**: 학술 연구 기준 Polymarket에서만 $40M+ 차익거래 수익 추출 (전체 시장).

## 베스트 프랙티스

### 마켓 스캔 워크플로우

```
전체 마켓 리스트 획득
  → Step 1: 거래량 필터 (일일 $10K+ 마켓만)
  → Step 2: 만기 필터 (7일-90일 잔여)
  → Step 3: 가격 비효율 체크 (YES+NO ≠ $1.00)
  → Step 4: 유동성 분석 (오더북 깊이, 스프레드)
  → Step 5: 정보 우위 평가 (해당 분야 전문 지식?)
  → Step 6: 포지션 사이징 (Kelly Criterion 적용)
  → Step 7: 주문 실행
```

### Kelly Criterion 적용

최적 베팅 크기 = (bp - q) / b

- b = 배당률 (= 1/가격 - 1)
- p = 승리 확률 추정치
- q = 패배 확률 (= 1 - p)

**예시**: 마켓 가격 $0.60, 실제 확률 추정 70%
- b = 1/0.60 - 1 = 0.667
- Kelly = (0.667 × 0.70 - 0.30) / 0.667 = 0.25 (자본의 25%)
- **실전**: 풀 Kelly는 위험이 크므로 **Half Kelly(12.5%)** 또는 **Quarter Kelly(6.25%)** 사용

### 포지션 관리 규칙

1. **단일 마켓 최대 노출**: 총 자본의 10%
2. **상관된 마켓 총 노출**: 총 자본의 25% (예: BTC 관련 마켓 전체)
3. **손절**: 포지션 대비 30% 손실 시 재평가. 50% 손실 시 의무 청산.
4. **이익 실현**: 목표 수익률 달성 시 50% 청산, 나머지 50%는 만기까지 보유.
5. **유동성 리스크**: 일일 거래량의 5% 이상 포지션 금지 (청산 어려움).

### 마켓 선택 기준

| 요소 | 최소 기준 | 이상적 |
|:---|:---|:---|
| 일일 거래량 | $10K | $100K+ |
| 만기까지 잔여 | 7일 이상 | 14-60일 |
| 오더북 깊이 | 양쪽 $1K+ | 양쪽 $10K+ |
| Bid-Ask 스프레드 | 5센트 이하 | 2센트 이하 |
| 가격 범위 | 0.10-0.90 | 0.20-0.80 |
| 정보 우위 | 약간의 엣지 | 명확한 엣지 |

## 주의사항 / 안티패턴

### 1. 과신 편향 (Overconfidence Bias)
"내 확률 추정이 90%인데 마켓이 70%라면 마켓이 틀렸다" — 이 생각이 위험하다. 마켓에는 당신이 모르는 정보가 반영되어 있을 수 있다. **마켓 가격과 크게 괴리되는 추정(20%+)은 반드시 재검토**.

### 2. 감정적 마켓 선택
스포츠 팬이 자기 팀 마켓에 베팅, 정치적 성향에 따라 후보 마켓 베팅 → **이해충돌(conflict of interest)**. 감정적 연결이 있는 마켓은 회피하거나, 역발상으로만 접근.

### 3. 유동성 함정 (Liquidity Trap)
거래량 $1K인 마켓에 $500 매수 → 시장 충격(market impact)으로 가격이 10센트+ 이동 → 평균 매입가가 크게 불리. **슬리피지를 항상 고려**.

### 4. 정산 리스크 (Resolution Risk)
Polymarket의 결과 판정이 불명확한 경우(예: "BTC가 $100K를 터치했는가?" — Coinbase에서는 터치, Binance에서는 미터치). 정산 기준(resolution source)을 반드시 사전 확인.

### 5. 기회비용 무시
$0.92에 YES를 매수하여 만기 시 $1.00을 받으면 8% 수익이지만, 만기가 6개월 후라면 연환산 16%. 같은 기간 DeFi에서 20% 수익이 가능하다면 → 기회비용 고려.

### 6. 확률의 합 ≠ 100% 맹신
다중 결과 마켓에서 합이 $0.95면 즉시 차익거래? 수수료(Taker 3%), 정산 시간(수일), 자금 잠김(lock-up)을 고려하면 실질 수익이 마이너스일 수 있다.

### 7. 상관 포지션 위험

### 포트폴리오 구성 원칙

1. **핵심(60%)**: 만기 1-4주, 고확률(0.85+), 높은 유동성 마켓. 연환산 20-40%.

4. **현금**: 항상 총 자본의 15-20%를 유동성으로 유지. 급작스러운 기회 대응용.
