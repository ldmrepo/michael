# Risk Manager (리스크 매니저) — Foundational Knowledge

## 역할 정의

리스크 매니저는 포트폴리오의 손실을 통제하고 자본을 보존하는 에이전트다. 수익을 극대화하는 것이 아니라 **파산(ruin)을 방지**하는 것이 최우선 목표다. 암호화폐 시장은 전통 금융보다 변동성이 2~5배 높고, 24/7 거래되며, 블랙스완 이벤트가 빈번하다. 이 환경에서 생존하기 위한 체계적 리스크 관리 프레임워크를 제공한다.

핵심 임무:
- 개별 포지션의 적정 크기(position sizing) 산출
- 포트폴리오 전체 리스크 노출(portfolio heat) 모니터링
- 손절/익절 수준 설정 및 관리
- Maximum Drawdown 한도 관리
- 극단적 시장 상황 대비 시나리오 준비
- 레버리지 사용 시 청산가 관리

이 에이전트는 "이 거래를 해야 하는가"가 아니라 "이 거래를 이 크기로 해도 되는가"를 판단한다.

## 핵심 개념

### 1. Kelly Criterion (켈리 기준)

1956년 Bell Labs의 John L. Kelly Jr.가 개발한 최적 베팅 크기 공식. 장기 자본 성장률을 최대화한다.

**기본 공식:**
```
f* = (bp - q) / b

f* = 최적 베팅 비율 (자본 대비)
b = 순 배당률 (이길 때 얻는 금액 / 질 때 잃는 금액)
p = 승률
q = 패률 (1 - p)
```

**예시:**
- 승률 55%, 손익비 2:1 → f* = (2 × 0.55 - 0.45) / 2 = 0.325 (자본의 32.5%)

**Fractional Kelly — 암호화폐 필수 조정:**

Full Kelly는 이론적 최적이나, 현실에서는 과도하게 공격적이다. 암호화폐 시장에서는 반드시 축소 적용해야 한다.

| Kelly 분율 | 적용 | 자본 성장 vs 위험 |
|-----------|------|-----------------|
| Full Kelly (100%) | 절대 사용 금지 | 이론적 최대 성장, 파산 위험 극도로 높음 |
| Half Kelly (50%) | 검증된 전략 + 높은 확신 시 | 성장률 75%, 변동성 50% 감소 |
| Quarter Kelly (25%) | 일반적 추천 수준 | 성장률 ~56%, 변동성 크게 감소 |
| Tenth Kelly (10%) | 초보자 / 신규 전략 / 고변동성 시장 | 성장률 ~19%, 매우 안전 |

**암호화폐에서의 Kelly 적용 한계:**
- 정확한 승률과 배당률 추정이 어려움 → 추정 오류가 Kelly 결과를 크게 왜곡
- 거래 비용(수수료, 슬리피지, 네트워크 수수료) 미반영
- 블랙스완 이벤트 미반영 (거래소 해킹, 규제 충격, 기술적 장애)
- 실전에서는 Fixed Fractional 방법과 병행 사용 권장

### 2. Position Sizing (포지션 사이징)

**Method 1: Fixed Fractional (고정 비율법)**

가장 실용적이고 널리 사용되는 방법.

```
Position Size = (Account × Risk%) / (Entry - StopLoss)

예: 계좌 $10,000, 리스크 1%, BTC $95,000 매수, 손절 $92,000
= ($10,000 × 0.01) / ($95,000 - $92,000)
= $100 / $3,000
= 0.0333 BTC ($3,167 포지션)
```

**리스크 비율 가이드라인:**

| 상황 | 거래당 리스크 | 근거 |
|------|------------|------|
| 보수적 / 초보자 | 0.5% | 200연패해도 계좌의 63%만 손실 |
| 일반적 | 1.0% | 전문 트레이더 표준. 100연패 = 63% 손실 |
| 공격적 (높은 확신) | 2.0% | 최대치. 50연패 = 63% 손실 |
| 절대 초과 금지 | 3.0% | 이 이상은 도박 |

**Method 2: Volatility-Based (변동성 기반)**

ATR(Average True Range)을 사용하여 현재 변동성에 맞게 포지션 크기를 자동 조절.

```
Position Size = (Account × Risk%) / (ATR × Multiplier)

ATR Multiplier 가이드:
- 보수적: 3.0 × ATR
- 일반적: 2.0 × ATR
- 공격적: 1.5 × ATR
```

변동성이 높으면 자연스럽게 포지션이 작아지고, 낮으면 커진다. 리스크 일정 유지에 효과적.

**Method 3: ATR-Based Stop Loss**

```
StopLoss = Entry - (ATR × Multiplier)

예: BTC Entry $95,000, ATR(14) = $2,500, Multiplier = 2.0
StopLoss = $95,000 - ($2,500 × 2) = $90,000
```

### 3. Maximum Drawdown (MDD) 관리

MDD는 포트폴리오가 최고점에서 최저점까지 하락한 최대 폭이다.

**암호화폐 역사적 MDD:**

| 자산 | 2018 약세장 | 2022 약세장 | 2025 조정 |
|------|-----------|-----------|----------|
| BTC | -84% | -77% | -30~40% |
| ETH | -94% | -82% | -40~50% |
| 알트코인 | -95~99% | -90~99% | -50~80% |

**MDD 제한 규칙:**

| 포트폴리오 MDD | 조치 |
|--------------|------|
| -10% | 경고. 포지션 크기 50% 축소 |
| -15% | 신규 진입 중단. 기존 포지션만 관리 |
| -20% | 전체 포지션의 50% 축소 |
| -25% | 포지션 75% 청산. 최소 포지션만 유지 |
| -30% | 전액 현금화 (circuit breaker). 최소 1주 쿨다운 |

**회복에 필요한 수익률:**

| 손실률 | 원금 회복에 필요한 수익률 |
|--------|---------------------|
| -10% | +11.1% |
| -20% | +25.0% |
| -30% | +42.9% |
| -50% | +100% |
| -75% | +300% |
| -90% | +900% |

이 표가 핵심이다. 손실이 커질수록 회복이 기하급수적으로 어려워진다. **방어가 공격보다 중요한 근본적 이유**.

### 4. Value at Risk (VaR)

특정 신뢰 수준에서 특정 기간 내 최대 예상 손실액.

**Parametric VaR (분산-공분산 방법):**
```
VaR = Portfolio Value × z-score × σ × √t

z-score: 95% CI = 1.645, 99% CI = 2.326
σ: 일별 수익률의 표준편차
t: 기간 (일)
```

**Historical VaR:**
과거 수익률 분포에서 직접 퍼센타일을 계산. 분포 가정이 불필요.
1. 과거 N일의 일별 수익률 수집 (최소 250일)
2. 수익률을 오름차순 정렬
3. 95% VaR = 하위 5% 퍼센타일 값

**암호화폐 VaR의 한계:**
- 암호화폐 수익률은 정규분포가 아님 (fat tails, 첨도 높음)
- 과거 데이터가 짧아 추정 불안정
- Regime change가 빈번 (규제, 해킹, 기술 발전)
- **Conditional VaR (CVaR / Expected Shortfall)** 병행 추천: VaR를 초과하는 손실의 평균값. Tail risk를 더 잘 포착

**실용적 적용:**
- BTC 일별 VaR (95%): 약 5~8% (시기에 따라 변동)
- ETH 일별 VaR (95%): 약 7~12%
- 알트코인: 10~25%+

### 5. 상관관계 리스크 (Correlation Risk)

**암호화폐 시장의 치명적 특성: 위기 시 상관관계 급등.**

| 상황 | BTC-ETH 상관관계 | BTC-알트 상관관계 |
|------|----------------|----------------|
| 평상시 | 0.6~0.8 | 0.4~0.7 |
| 급등장 | 0.5~0.7 | 0.3~0.6 |
| 급락장 | 0.85~0.95 | 0.80~0.95 |

**핵심 교훈:**
- 분산 투자가 위기 시 무력화됨. "모든 코인이 함께 떨어진다"
- BTC 비중이 사실상 포트폴리오 리스크를 지배
- 진정한 분산은 **자산 클래스 간** 분산 (현금, 스테이블코인, 예측 마켓 등)
- Stablecoin 비중 유지가 가장 효과적인 리스크 관리 도구

### 6. Stop-Loss 전략

**유형별 비교:**

| 전략 | 설명 | 장점 | 단점 |
|------|------|------|------|
| Fixed Stop | 진입가 대비 고정 % | 단순, 명확 | 변동성 미반영 |
| ATR Stop | ATR 기반 동적 조절 | 변동성 적응 | 계산 복잡 |
| Trailing Stop | 최고가 대비 % 하락 시 발동 | 수익 보호 | Whipsaw에 취약 |
| Time Stop | 일정 기간 내 목표 미도달 시 청산 | 자본 효율성 | 긴 추세에 부적합 |
| Volatility Stop | Keltner/BB 기반 | 시장 적응적 | 세팅 최적화 필요 |

**암호화폐 Stop-Loss 세팅 가이드:**

| 자산 | 스윙 트레이딩 | 포지션 트레이딩 |
|------|------------|-------------|
| BTC | 3~5% | 8~15% |
| ETH | 5~8% | 10~20% |
| 대형 알트 (Top 20) | 8~12% | 15~25% |
| 소형 알트 | 12~20% | 사용 자제 (유동성 부족) |

**Stop-Loss 원칙:**
- 진입 전에 손절가를 반드시 결정할 것
- 감정적으로 손절가를 옮기지 않을 것 (특히 확대 방향)
- 수익 구간에서는 trailing stop으로 전환
- 손절 후 즉시 재진입하지 않을 것 (최소 1시간 쿨다운)

### 7. Take-Profit 전략

**단계적 익절 (Scaling Out):**
```
총 포지션 100을 3단계로 익절:
1차 익절: 포지션 33% @ 1R (리스크 대비 1배 수익)
2차 익절: 포지션 33% @ 2R
3차 익절: 나머지 34% @ trailing stop
```

**Risk-Reward Ratio 가이드:**

| 최소 R:R | 적용 상황 |
|---------|---------|
| 1:1 | 스캘핑 (높은 승률 필요 > 60%) |
| 1:2 | 스윙 트레이딩 표준 (승률 40%면 수익) |
| 1:3 | 포지션 트레이딩 (승률 30%로도 수익) |
| 1:5+ | 추세 추종 (낮은 승률, 큰 수익 추구) |

### 8. Portfolio Heat (포트폴리오 열)

전체 포트폴리오에서 동시에 리스크에 노출된 자본 비율.

```
Portfolio Heat = Σ (각 포지션의 Open Risk)
Open Risk = (Entry - Current StopLoss) × Position Size / Total Capital
```

**Portfolio Heat 한도:**

| Heat | 상태 | 조치 |
|------|------|------|
| 0~3% | 보수적 | 신규 진입 가능 |
| 3~5% | 적정 | 일반적 운용 수준 |
| 5~8% | 주의 | 신규 진입 제한, 기존 포지션 관리 집중 |
| 8~10% | 위험 | 신규 진입 금지, 일부 포지션 축소 검토 |
| 10%+ | 과열 | 즉시 포지션 축소 필요 |

### 9. Black Swan 대비

**암호화폐 역사적 블랙스완 사례:**
- 2014 Mt. Gox 해킹 (BTC -50% in days)
- 2017 중국 ICO/거래소 금지 (BTC -40%)
- 2020 COVID Crash (BTC -50% in 2 days)
- 2021 중국 채굴 금지 (BTC -55%)
- 2022 LUNA/UST 붕괴 (전체 시장 -60%)
- 2022 FTX 파산 (BTC -25%, 전체 시장 신뢰 붕괴)

**대비 전략:**
1. **현금 비중 최소 20% 유지**: 급락 시 매수 기회 + 심리적 안정
2. **단일 거래소 집중 금지**: 자산을 2개 이상 거래소/지갑에 분산
3. **레버리지 제한**: 최대 3배. 가능하면 1배 (현물)
4. **스테이블코인 분산**: USDC + USDT 혼합. 단일 스테이블코인 의존 금지 (UST 교훈)
5. **자동 위험 관리**: 주요 포지션에 손절 주문 항상 설정

### 10. 레버리지 리스크 관리

**청산가 계산:**

```
Long 청산가 = Entry × (1 - 1/Leverage + Maintenance Margin Rate)
Short 청산가 = Entry × (1 + 1/Leverage - Maintenance Margin Rate)

예: BTC $95,000 Long, 10x 레버리지, MM Rate 0.5%
청산가 = $95,000 × (1 - 0.1 + 0.005) = $95,000 × 0.905 = $85,975
```

**레버리지 가이드라인:**

| 레버리지 | 적합 용도 | 청산 마진 (BTC) |
|---------|---------|---------------|
| 1x | 현물 거래. 리스크 최소 | 청산 없음 |
| 2~3x | 보수적 마진. 숙련자에게 적합 | -33~50% |
| 5x | 주의 필요. 단기 트레이딩만 | -20% |
| 10x | 위험. 스캘핑 전용 | -10% |
| 20x+ | 극도로 위험. 사용 자제 | -5% 이하 |

## 베스트 프랙티스

### 일일 리스크 체크리스트

1. 전체 포트폴리오 Heat 확인 (< 6%)
2. 모든 포지션의 Stop-Loss 작동 여부 확인
3. 가장 큰 포지션이 전체의 25%를 초과하지 않는지 확인
4. 현금/스테이블코인 비중 20% 이상 유지 확인
5. 오늘 만기되는 포지션이나 이벤트 확인 (FOMC, CPI 등)
6. 레버리지 포지션의 청산가 대비 현재가 거리 확인

### 매매 전 필수 질문

- 이 거래에서 최대 얼마를 잃을 수 있는가?
- 그 손실이 전체 자본의 몇 %인가?
- 동시에 모든 포지션이 손절될 경우 총 손실은?
- 최악의 시나리오(gap, 슬리피지)에서 실제 손실은 설정한 손절보다 얼마나 클 수 있는가?

### 리스크 보고서 작성 원칙

- 현재 포트폴리오 Heat을 숫자로 명시
- 최대 손실 시나리오를 구체적 금액으로 표현
- 가장 위험한 포지션을 식별하고 이유 설명
- 리스크 한도 초과 시 구체적 조치 방안 제시

## 주의사항 / 안티패턴

### 절대 하지 말 것

1. **손절가 없이 진입**: 모든 포지션에 손절가 필수. "BTC는 결국 오른다"는 투자가 아니라 도박
2. **물타기 (Averaging Down) 남용**: 하락 중 추가 매수는 리스크 증가. 사전 계획된 분할 매수만 허용
3. **전체 자본 투입**: 어떤 상황에서도 100% 투입 금지. 최소 20% 현금 유지
4. **감정적 손절가 변경**: 진입 후 손절가를 불리한 방향으로 이동 금지
5. **손실 복구를 위한 포지션 증가**: "본전 찾기" 심리로 다음 거래 크기를 키우는 것은 파산의 지름길
6. **상관관계 무시한 분산**: BTC, ETH, SOL, AVAX를 동시에 롱하면 분산이 아니라 집중
7. **레버리지로 부족한 자본 보충**: 자본이 부족하면 더 작게 거래해야지, 레버리지로 늘리면 안 됨

### 심리적 함정

- **Disposition Effect**: 수익 포지션은 너무 일찍 청산, 손실 포지션은 너무 오래 보유하는 경향
- **Recency Bias**: 최근 수익에 취해 리스크를 과소평가
- **Sunk Cost Fallacy**: "이미 이만큼 잃었으니 더 버텨야 한다" → 추가 손실
- **Overconfidence**: 연승 후 포지션 크기를 급격히 키움

### 포지션 크기 결정 흐름도

```
1. 현재 Portfolio Heat 확인
   → 8% 초과면 → 신규 진입 금지

2. 거래당 리스크 결정 (0.5~2%)
   → 시장 변동성 높으면 0.5%
   → 높은 확신 + 낮은 변동성이면 2%

3. 손절가 결정 (ATR 또는 기술적 레벨)

4. 포지션 크기 계산
   = (계좌 × 리스크%) / (진입가 - 손절가)

5. 최대 단일 포지션 한도 확인 (전체의 25%)
   → 초과하면 축소

6. 최종 Portfolio Heat 재계산
   → 한도 내면 → 진입
   → 초과면 → 포지션 축소 또는 기존 포지션 정리 후 진입
```
