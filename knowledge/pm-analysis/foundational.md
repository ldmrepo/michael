# Prediction Market Probability Analyst (예측시장 확률 분석가) — Foundational Knowledge

## 역할 정의

예측시장 확률 분석가는 Polymarket 등 예측 마켓에서 거래되는 이벤트의 **실제 확률(true probability)**을 독립적으로 추정하고, 시장 가격과 비교하여 **기대값 양의 포지션(positive expected value)**을 식별하는 에이전트다.

핵심 임무:
- 이벤트의 독립적 확률 추정 (시장 가격에 앵커링 되지 않고)
- Bayesian updating으로 새로운 정보 반영
- 시장 가격과 추정 확률의 차이(edge) 계산
- 확률 편향(bias) 식별 및 보정
- 시장 비효율성(mispricing) 탐지
- 포지션의 기대값과 확신 수준 보고

이 에이전트의 출력은 "이 사건이 일어날 확률은 X%이고, 시장 가격 Y%와의 차이는 Z%p이며, 이 추정에 대한 확신 수준은 [높음/중간/낮음]이다"와 같은 구조화된 확률 판단이다.

## 핵심 개념

### 1. Bayesian Updating (베이지안 갱신)

모든 확률 추정의 핵심 프레임워크. 새로운 증거가 나타날 때마다 사전 확률(prior)을 갱신하여 사후 확률(posterior)을 구한다.

**Bayes' Theorem:**
```
P(H|E) = P(E|H) × P(H) / P(E)

P(H|E) = 사후 확률 (증거 E를 본 후 가설 H의 확률)
P(H) = 사전 확률 (증거 전 가설의 확률)
P(E|H) = 우도 (가설이 참일 때 증거가 관찰될 확률)
P(E) = 증거의 한계 확률
```

**Odds Ratio 방식 (더 직관적):**
```
Posterior Odds = Prior Odds × Likelihood Ratio

Likelihood Ratio (LR) = P(E|H) / P(E|¬H)
```

**실전 예시: "연준이 다음 FOMC에서 금리를 인하할 확률"**
- Prior: 시장 가격 기반 35% (CME FedWatch)
- 새로운 증거: 예상보다 낮은 CPI 발표
- P(낮은 CPI | 금리 인하) = 0.70
- P(낮은 CPI | 금리 동결) = 0.30
- LR = 0.70 / 0.30 = 2.33
- Prior Odds = 0.35 / 0.65 = 0.538
- Posterior Odds = 0.538 × 2.33 = 1.254
- Posterior Probability = 1.254 / (1 + 1.254) = 55.6%

**핵심 원칙:**
- 하나의 증거로 확률을 급격히 변경하지 않을 것 (extraordinary claims require extraordinary evidence)
- LR > 3이면 강한 증거, LR > 10이면 매우 강한 증거, LR > 100이면 결정적 증거
- 여러 독립 증거의 LR은 곱셈. LR 2.0인 독립 증거 3개 = 종합 LR 8.0

### 2. Base Rate (기저율)

**Base Rate Neglect — 가장 흔하고 치명적인 편향.**

사람들은 구체적인 이야기나 최근 사건에 끌려 기저율을 무시하는 경향이 있다.

**예시:**
- "이 정치인이 당선될 것 같다" → 해당 정당의 역대 당선율은? 현직 대통령 재선율은?
- "BTC가 $200K 돌파할 것이다" → 역사적으로 사이클당 최대 상승률은?
- "이 팀이 우승할 것이다" → 해당 리그의 우승 후보 적중률은?

**기저율 활용 체크리스트:**
1. 유사한 과거 사건의 빈도를 먼저 조사
2. 해당 빈도를 prior probability로 설정
3. 이번 사건의 특수한 상황을 evidence로 Bayesian update
4. 기저율에서 크게 벗어나는 추정을 할 때는 강력한 근거 필요

**주요 기저율 참고:**
- 미국 대통령 재선율: ~57% (27전 14승 13패 — 1900년 이후)
- 미국 현직 대통령 당 후보 재지명률: ~85%
- 암호화폐 프로젝트 3년 생존율: ~10~20%
- FOMC 금리 결정 시장 예측 정확도 (1개월 전): ~75~85%
- 스포츠 시즌 전 우승 후보 1순위 실제 우승율: ~20~30% (리그별 차이)

### 3. Calibration (보정)

자신의 확률 추정이 얼마나 정확한지 측정하고 개선하는 과정.

**Brier Score:**
```
Brier Score = (1/N) × Σ(forecast - outcome)²

forecast: 예측 확률 (0~1)
outcome: 실제 결과 (0 또는 1)
```

| Brier Score | 해석 |
|------------|------|
| 0.000 | 완벽한 예측 (불가능) |
| < 0.100 | 우수 (전문 예측가 수준) |
| 0.100~0.125 | 양호 |
| 0.125~0.200 | 보통 |
| 0.200~0.250 | 동전 던지기(0.25)보다 약간 나은 수준 |
| 0.250 | 항상 50%로 예측한 것과 동일 (무능) |
| > 0.250 | 동전 던지기보다 못함 (역으로 쓰면 유용) |

**Polymarket의 Brier Score:** 12시간 전 예측 기준 약 0.058 — 매우 우수한 수준. 이것이 시장을 이기기 어려운 이유.

**Log Score (더 극단 예측에 민감):**
```
Log Score = log(forecast)  if outcome = 1
          = log(1-forecast) if outcome = 0
```
90% 예측이 틀렸을 때 (-2.30)의 페널티가 60% 예측이 틀렸을 때 (-0.92)보다 훨씬 큼.

**자기 보정 방법:**
1. 모든 예측을 기록 (날짜, 이벤트, 확률, 결과)
2. 예측을 확률 구간별로 그룹화 (예: 80~90% 그룹)
3. 각 그룹의 실제 발생률 확인
4. "80%로 예측한 것들이 실제로 80% 발생했는가?" 확인
5. 체계적 편향 발견 시 보정 (예: 내가 80%라고 하면 실제로는 65% → overconfidence)

### 4. 확률 편향 카탈로그 (Probability Bias Catalog)

**Anchoring (앵커링):**
- 시장 현재 가격에 자신의 추정이 끌려가는 것
- 대응: 시장 가격을 보기 전에 독립적 추정을 먼저 수행
- 시장 가격 85%를 보고 나면, 실제로는 60%인 이벤트도 75~80%로 추정하게 됨

**Availability Bias (가용성 편향):**
- 최근에 본 뉴스나 기억하기 쉬운 사건의 확률을 과대평가
- "테러 뉴스를 많이 봤으니 테러 확률이 높다" → 실제 기저율은 매우 낮음
- 대응: 항상 기저율부터 시작

**Representativeness (대표성 편향):**
- 특정 사건이 특정 범주에 "보이는" 것만으로 확률을 판단
- "이 코인 팀이 우수하니 성공할 것" → 우수한 팀의 프로젝트도 대부분 실패
- 대응: 기저율 + Bayesian update

**Conjunction Fallacy (결합 오류):**
- P(A and B) ≤ P(A) 인데, 구체적 시나리오가 더 그럴듯해 보여 확률을 높게 평가
- "BTC가 $150K 돌파 AND ETH가 $10K 돌파" 확률 < "BTC가 $150K 돌파" 확률
- 대응: 결합 확률 = P(A) × P(B|A). 항상 개별 확률 이하

**Overconfidence (과신):**
- 가장 보편적이고 위험한 편향. 90% 확신한 것의 실제 정확도는 약 70~75%
- 대응: 확률 추정 후 10~15% 방향으로 50%에 가깝게 조정 (extremize하지 않기)
- "내가 90%라고 생각하면 실제로는 80%일 가능성이 높다"

**Narrative Bias (서사 편향):**
- 그럴듯한 이야기가 있으면 확률을 과대평가
- "중국이 규제를 풀면 → 기관 자금 유입 → BTC 폭등" — 각 단계의 확률을 곱하면 전체 확률은 매우 낮음
- 대응: 인과 사슬의 각 단계별 확률을 명시적으로 계산

### 5. Edge Calculation (엣지 계산)

**Expected Value (기대값):**
```
EV = (Prob_win × Payout_win) - (Prob_lose × Cost_lose)

예: True probability = 70%, Market price = $0.60 (YES)
Buy YES:
EV = (0.70 × $0.40) - (0.30 × $0.60) = $0.28 - $0.18 = +$0.10 per dollar

Edge = True Prob - Market Price = 70% - 60% = +10%p
```

**최소 Edge 기준:**

| Edge | 판단 | 조치 |
|------|------|------|
| < 3%p | Noise 수준 | 거래 안 함 |
| 3~5%p | 약한 엣지 | 소량 거래 가능 (높은 확신 시) |
| 5~10%p | 보통 엣지 | 정상 거래 크기 |
| 10~20%p | 강한 엣지 | 적극 거래, 포지션 확대 가능 |
| > 20%p | 매우 강한 엣지 | 왜 이렇게 큰 엣지가 존재하는지 재검증 필요 |

**주의: 큰 엣지는 의심해야 한다.**
- 20%p 이상의 엣지가 보이면 "시장이 틀렸다"가 아니라 "내가 놓친 정보가 있는가?" 먼저 자문
- 시장에는 내가 모르는 정보를 가진 참가자가 있을 수 있음
- 유동성이 낮은 마켓에서만 큰 엣지가 존재하는 경향

### 6. Kelly Criterion for Prediction Markets

예측 마켓에서의 최적 베팅 크기:
```
f* = (p × (1/market_price) - 1) / ((1/market_price) - 1)

간소화:
f* = (p - market_price) / (1 - market_price)

예: True prob = 70%, Market price = $0.60
f* = (0.70 - 0.60) / (1 - 0.60) = 0.10 / 0.40 = 25%
Quarter Kelly = 6.25% of bankroll
```

**예측 마켓 Kelly 특수 고려사항:**
- 추정 확률의 불확실성이 높으면 Kelly 분율을 낮춰야 함
- 정산까지 시간이 긴 마켓은 기회비용 반영 (자본이 묶임)
- 바이너리 마켓 vs 다중 결과 마켓에서 계산 방법이 다름
- 관련 마켓 간 상관관계 고려 (동일 이벤트의 YES/NO 마켓)

### 7. 정보원 신뢰도 가중치

| 정보원 | 신뢰도 | LR 범위 | 비고 |
|--------|--------|---------|------|
| 공식 발표 (정부, 기관) | 매우 높음 | 10~100 | 확정적 증거 |
| 주요 통신사 속보 (AP, Reuters) | 높음 | 5~20 | 검증된 보도 |
| 전문가 의견 (해당 분야) | 중-높음 | 2~5 | 전문성에 따라 가변 |
| 시장 가격 자체 | 중-높음 | 2~5 | 집단 지성 반영 |
| 소셜 미디어 (X/Twitter) | 낮음-중 | 1.2~2 | 노이즈 많음, 속보성에 가치 |
| 루머/미확인 소식 | 매우 낮음 | 1.05~1.3 | 확인 전까지 근거 약함 |
| 익명 소스 | 매우 낮음 | 1.01~1.2 | 거의 무시 |

### 8. Scenario Analysis (시나리오 분석)

복잡한 이벤트를 시나리오로 분해하여 확률을 구조화하는 방법.

**MECE 원칙 (Mutually Exclusive, Collectively Exhaustive):**
- 시나리오들이 서로 겹치지 않고, 모든 가능성을 포괄해야 함
- 모든 시나리오 확률의 합 = 100%

**예시: "다음 FOMC에서 금리 결정"**
```
시나리오 1: 50bp 인하 → 5%
시나리오 2: 25bp 인하 → 30%
시나리오 3: 동결 → 55%
시나리오 4: 25bp 인상 → 9%
시나리오 5: 50bp 인상 → 1%
합계: 100%
```

각 시나리오별로:
- BTC 반응 예상
- 예측 마켓 포지션의 가치 변화
- 포트폴리오 영향 계산

### 9. Conditional Probability Chains (조건부 확률 체인)

복합 이벤트의 확률을 계산할 때 각 단계의 조건부 확률을 연결한다.

```
P(A and B and C) = P(A) × P(B|A) × P(C|A,B)

예: "BTC ETF 승인 AND 기관 자금 $10B 유입 AND BTC $200K"
P(ETF 승인) = 0.90
P($10B 유입 | ETF 승인) = 0.50
P($200K | ETF 승인 AND $10B 유입) = 0.40
P(전체) = 0.90 × 0.50 × 0.40 = 0.18 (18%)
```

**함정:** 각 단계가 합리적으로 보여도 곱하면 전체 확률은 급격히 낮아짐.

### 10. Time Decay in Prediction Markets

**시간에 따른 확률 수렴 패턴:**
- 정산일이 가까워질수록 가격은 0 또는 1에 수렴
- 이미 높은 확률 (>85%)의 마켓은 시간 경과 시 추가 엣지가 작아짐
- 낮은 확률 (<15%)의 NO 포지션은 시간이 지나면서 수익이 실현됨 (price → $1.00)

**시간가치 계산:**
```
Annualized Return = (Edge / Market_Price) / (Days_to_Resolution / 365)

예: Edge 5%p, 시장가 $0.90 (YES), 정산까지 30일
AR = (0.05 / 0.90) / (30 / 365) = 0.0556 / 0.0822 = 67.6% annualized
```

**시간 기반 필터:**
- 정산 30일 이내 + Edge > 3%p → 매력적
- 정산 90일 이내 + Edge > 7%p → 매력적
- 정산 180일 이상 + Edge > 15%p → 자본 효율성 낮음. 다른 기회와 비교

## 베스트 프랙티스

### 확률 추정 프로세스 (매 분석마다 따를 것)

1. **시장 가격 확인 전에 독립적 prior 설정** (앵커링 방지)
2. **기저율 조사** — 유사한 과거 사건의 빈도
3. **현재 상황의 특수성 평가** — Bayesian LR 추정
4. **Update 수행** — Prior × LR = Posterior
5. **편향 체크** — Overconfidence? Narrative? Anchoring?
6. **확신 수준 분류** — High/Medium/Low
7. **시장 가격과 비교** — Edge 계산
8. **Edge > 최소 기준?** — YES면 포지션 추천, NO면 pass

### 확률 보고 형식

```
마켓: [마켓 이름]
시장 가격: [YES/NO @ $X.XX]
독립 추정 확률: [X%]
Edge: [+/-X%p]
확신 수준: [High/Medium/Low]
근거: [1~3줄 요약]
주요 불확실성: [무엇이 추정을 바꿀 수 있는가]
추천: [BUY YES/BUY NO/PASS]
```

## 주의사항 / 안티패턴

### 절대 하지 말 것

1. **시장 가격을 prior로 사용**: 시장 가격은 비교 대상이지 시작점이 아님. 독립 추정을 먼저 수행
2. **정보 없이 기저율에서 크게 벗어나기**: "이번은 다르다"는 거의 항상 틀림. 특별한 증거 없이 기저율에서 20%p 이상 이탈 금지
3. **확률 0% 또는 100% 부여**: 어떤 이벤트도 0%나 100%가 아님. 최소 1%, 최대 99%
4. **서사(narrative)에 확률 부풀리기**: 그럴듯한 이야기 ≠ 높은 확률. 인과 체인의 곱을 계산할 것
5. **확인 편향(confirmation bias)**: 자신의 포지션을 지지하는 정보만 수집하는 경향. 반대 시나리오를 의도적으로 구성
6. **무시할 수 없는 엣지를 무시**: 5%p 엣지가 작아 보여도, 연간 수십 건이면 상당한 수익
7. **상관된 마켓을 독립 취급**: "BTC $100K" 마켓과 "BTC $120K" 마켓은 독립이 아님

### 시장이 비효율적인 경우 vs 내가 틀린 경우

**시장이 비효율적일 가능성이 높은 경우:**
- 유동성이 매우 낮은 마켓 (총 거래량 < $50K)
- 니치한 주제 (전문 지식 보유 시 정보 우위)
- 새로 열린 마켓 (가격 발견 진행 중)
- 이벤트 직전 급변하는 정보 (시장 반응 지연)

**내가 틀렸을 가능성이 높은 경우:**
- 유동성이 높은 마켓 (총 거래량 > $1M) — 많은 참가자의 집단 지성
- 내 추정과 시장 가격 차이가 20%p 이상 — 내가 놓친 정보 가능성
- 해당 분야 전문 지식 없이 직감으로 판단
- 시장 가격이 장기간 안정적으로 유지되는 경우
