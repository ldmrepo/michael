# On-chain Analyst (온체인 분석가) — Foundational Knowledge

## 역할 정의

온체인 분석가는 블록체인에 기록된 **불변의 트랜잭션 데이터**를 분석하여 시장 참여자의 실제 행동을 파악하는 에이전트다. 가격과 거래량은 거래소가 보고하는 데이터(조작 가능)이지만, 온체인 데이터는 **블록체인이라는 진실의 원장(ledger of truth)**에서 직접 추출한다.

이 에이전트가 존재하는 이유: 소셜 미디어에서 "강세"를 외치면서 실제로는 물량을 거래소로 보내는 고래, ETF 유입을 발표하면서 실제로는 순유출이 발생하는 펀드, 낙관적 전망을 내놓으면서 스테이블코인을 인출하는 기관 — 온체인 데이터는 **말이 아닌 행동**을 보여준다. "Don't trust, verify" — 이것이 온체인 분석의 철학이다.

## 핵심 개념

### 1. 고래 행동 패턴 (Whale Behavior Patterns)

**고래 정의**: BTC 기준 1,000 BTC 이상 보유 주소 (약 $80M+ at $80K/BTC).

#### 고래 유형 분류

| 유형 | 보유량 | 행동 패턴 | 시장 영향 |
|:---|:---|:---|:---|
| **기관 고래 (Institutional)** | 10K+ BTC | 느리고 체계적. OTC 선호. 온체인 흔적 적음. | 장기 방향 설정 |
| **초기 채굴자 (Early Miner)** | 1K-50K BTC | 수년간 휴면. 이동 시 시장 패닉 유발. | 희소하지만 영향 큼 |
| **거래소 고래 (Exchange Whale)** | 1K-10K BTC | 거래소에서 활발히 매매. 가격 변동 직접 유발. | 단기 영향 강함 |
| **DeFi 고래** | $10M+ TVL | 유동성 풀 진입/이탈. 프로토콜 레벨 영향. | DeFi 토큰에 강한 영향 |

#### 고래 행동 해석

- **축적 (Accumulation)**: 고래 지갑 잔고 증가 + 거래소 잔고 감소 = 강세 신호
- **분배 (Distribution)**: 고래 지갑에서 거래소로 이동 + 소규모 지갑으로 분산 = 약세 신호
- **재편 (Rotation)**: BTC → ETH, ETH → 알트코인 등 자산 간 이동 = 섹터 로테이션
- **휴면 이동 (Dormant Activation)**: 1년+ 미움직인 BTC가 이동 = 매도 의도 가능성 높음

**2025년 데이터**: $1M+ 트랜잭션이 2025년 12월 4주 최고치 기록. 그러나 $100K+ 트랜잭션은 감소 — 소수의 초대형 플레이어만 선택적 축적 중. Gini 계수 0.4675 → 0.4677로 미세 상승 (부 집중도 증가).

### 2. ETF 자금 흐름 해석 (ETF Fund Flow Interpretation)

BTC ETF는 2024년 1월 이후 온체인 분석의 **새로운 핵심 변수**가 되었다.

**2025년 실적**: 8월까지 $29.4B 순유입. 총 AUM $156B (76개 ETF/ETP).

#### ETF 흐름 해석 프레임워크

| 흐름 패턴 | 의미 | BTC 가격 영향 |
|:---|:---|:---|
| 일일 순유입 $100M+ | 기관 매수 지속 | 상방 압력 |
| 일일 순유입 $500M+ | 강한 기관 수요 | 강한 상방 |
| 일일 순유출 $100M+ | 기관 차익실현 또는 리스크 오프 | 하방 압력 |
| 일일 순유출 $500M+ | 대규모 이탈 | 강한 하방 |
| GBTC 유출 > 전체 유입 | Grayscale 프리미엄 차익거래 잔여 | 구조적 매도 (2024 패턴) |
| 유입 둔화 (양수이나 감소 추세) | 수요 피크 접근 | 모멘텀 약화 |

**ETF 시대의 온체인 분석 변화**:
- 전통적 NVT(Network Value to Transactions) 비율이 **덜 신뢰**적으로 변함. ETF 거래는 온체인이 아닌 오프체인에서 발생하므로, NVT가 과대평가 신호를 보낼 수 있음.
- 거래소 잔고 감소가 반드시 "HODLing" 의미가 아님 — ETF 커스터디안(BitGo, Coinbase Custody)으로 이동일 수 있음.
- **ETF 유입량 + 온체인 거래소 유출량**을 결합하여 실질 수요 추정이 더 정확.

### 3. 거래소 유입/유출 (Exchange Inflow/Outflow)

온체인에서 가장 직관적이고 신뢰도 높은 지표.

**기본 원칙**:
- **거래소 유입(Inflow) 증가**: 매도 의도 → 약세 신호
- **거래소 유출(Outflow) 증가**: 장기 보유 의도 → 강세 신호
- **스테이블코인 거래소 유입 증가**: 매수 대기 자금 → 강세 신호
- **스테이블코인 거래소 유출 증가**: 매수 의지 감소 → 약세 신호

**핵심 임계값 (BTC 기준)**:

| 지표 | 정상 | 주의 | 경보 |
|:---|:---|:---|:---|
| 일일 순유입 | ±5K BTC | 10K+ BTC 유입 | 30K+ BTC 유입 |
| 일일 순유출 | ±5K BTC | 10K+ BTC 유출 | 30K+ BTC 유출 |
| 거래소 잔고 (총합) | 안정적 | 1주 3% 변동 | 1주 5%+ 변동 |

**2025-2026년 동향**: 거래소 잔고가 다년 최저치로 하락 (BTC 기준 ~2.3M BTC, 전고점 대비 -25%). $100K 돌파와 동시에 발생하여, 공급 제약(supply squeeze) + ETF 수요 결합 → 구조적 상방 압력.

### 4. MVRV / SOPR / NVT 비율 (Core On-chain Ratios)

#### MVRV (Market Value to Realized Value)

시가총액 / 실현 시가총액. 보유자의 **평균 손익 상태**를 보여줌.

- **Realized Cap**: 각 UTXO(미사용 트랜잭션 출력)가 마지막으로 이동한 시점의 가격으로 계산한 총 가치

| MVRV 값 | 의미 | 역사적 패턴 |
|:---|:---|:---|
| < 1.0 | 평균 보유자가 손실 상태 | **강한 매수 구간**. 역사적 바닥 (2015, 2018, 2022) |
| 1.0 - 2.0 | 보유자 약간의 이익 | 정상 범위. 축적/보유 구간 |
| 2.0 - 3.5 | 보유자 큰 이익 | 이익 실현 시작. 주의 구간 |
| > 3.5 | 극도의 이익 | **강한 매도 구간**. 역사적 고점 (2013, 2017, 2021) |

**MVRV Z-Score**: 표준편차로 정규화한 버전. 7 이상 = 과열, 0 이하 = 저평가.
- 2026년 1월 기준: Z-Score 1.32 — "과열 구간(7+)" 한참 아래. 성장 여력 존재.

#### SOPR (Spent Output Profit Ratio)

이동된 코인의 매도 가격 / 매입 가격. 실현 손익 비율.

| SOPR 값 | 의미 | 액션 |
|:---|:---|:---|
| > 1.05 | 이익 실현 매도 활발 | 매도 압력 증가 주의 |
| 1.00 - 1.05 | 약간의 이익으로 매도 | 정상 범위 |
| = 1.00 | 손익분기점에서 매도 | **핵심 지지/저항선**. 강세장에서 1.0이 지지 |
| < 1.00 | 손실 상태에서 매도 (항복) | 약세장: 계속 하락 가능. 하지만 1.0 미만이 장기화되면 바닥 근접 |

**aSOPR** (Adjusted SOPR): 1시간 이내 이동(체인 내부 이동)을 제외. 실질적 매도 행동만 반영하므로 더 신뢰적.

#### NVT (Network Value to Transactions)

시가총액 / 일일 온체인 거래량. 네트워크 "P/E 비율".

| NVT 값 | 전통적 해석 | 2025년 수정 해석 |
|:---|:---|:---|
| < 25 | 저평가 (거래량 대비 시총 낮음) | 유효하나, L2/LN 거래 미포함 주의 |
| 25 - 65 | 적정 가치 | 정상 범위 |
| > 65 | 고평가 (거래량 대비 시총 높음) | **ETF 시대에는 신뢰도 하락**. 오프체인 ETF 거래량 미포함 |

**중요**: NVT는 ETF 도입 후 신뢰도가 상당히 하락. Lightning Network, L2 솔루션, ETF 오프체인 거래 등이 실제 경제 활동을 반영하지 못하게 만듦. 보조 지표로만 사용.

### 5. UTXO 연령 분석 (UTXO Age Analysis / HODL Waves)

각 UTXO가 마지막으로 이동한 이후 경과 시간을 분류.

**HODL Wave 밴드**:

| 연령 | 보유자 유형 | 매도 시 의미 |
|:---|:---|:---|
| < 1일 | 초단기 트레이더 | 일상적 거래. 노이즈. |
| 1일 - 1주 | 단기 트레이더 | 활발한 거래 구간. |
| 1주 - 1개월 | 스윙 트레이더 | 중기 심리 반영. |
| 1-3개월 | 중기 보유자 | 이 구간의 매도 증가 = 모멘텀 약화 |
| 3-6개월 | 반 장기 보유자 | 이전 사이클의 매수자가 이익 실현 시작 |
| 6-12개월 | 장기 보유자 | **매도 증가 = 사이클 고점 접근 신호** |
| 1-2년 | 강한 장기 보유자 | 사이클 횡단 보유자. 매도 시 매우 강한 신호. |
| 2-5년 | 코어 HODLer | 거의 매도 안 함. 이동 시 시장 패닉 가능. |
| 5년+ | 원년 멤버/분실 | 분실 코인 포함. 이동 시 큰 뉴스. |

**Long-Term Holder (LTH) Supply**: 155일 이상 미이동 BTC. 전체 공급의 60-70%가 LTH에 의해 보유. LTH 공급 비율이 정점에서 감소 전환 시 = 분배 시작 = 사이클 후반.

**Short-Term Holder (STH) Cost Basis**: STH(155일 미만 보유자)의 평균 매입가. 강세장에서 이 가격이 지지선 역할. 하회 시 패닉 매도 가속화.

### 6. 마이너 행동 (Miner Behavior)

#### Miner Revenue & Hash Rate

- **Hash Rate 상승**: 네트워크 보안 강화. 마이너의 장기적 수익 기대 반영. 강세 신호.
- **Hash Rate 하락**: 마이너 이탈(비용 > 수익). 캐피튤레이션 가능. 약세 구간이나 바닥 신호일 수 있음.
- **Hash Ribbon**: 30일 이평선이 60일 이평선을 상향 돌파 시 = 마이너 캐피튤레이션 종료 = **역사적 매수 신호** (2012, 2015, 2019, 2020, 2022에 모두 작동).

#### Miner Outflow

- 마이너 지갑 → 거래소 대량 이동: 마이너가 운영비 충당을 위해 매도. 하방 압력.
- Puell Multiple > 4: 마이너 수익이 과도 → 매도 인센티브 높음 → 고점 신호.
- Puell Multiple < 0.5: 마이너 수익이 과소 → 캐피튤레이션 구간 → 바닥 신호.

### 7. 스테이블코인 공급 변화 (Stablecoin Supply Shifts)

스테이블코인은 암호화폐 시장의 **대기 자금(dry powder)**.

**2025년 데이터**: Q3에만 $41B 순유입 — 2021년 이후 최대.

| 지표 | 강세 신호 | 약세 신호 |
|:---|:---|:---|
| 스테이블코인 총 공급 | 증가 (자금 유입) | 감소 (자금 유출) |
| 거래소 스테이블코인 잔고 | 증가 (매수 대기) | 감소 (이미 매수 완료 또는 이탈) |
| USDT Dominance | 하락 (리스크 온) | 상승 (리스크 오프, 현금화) |
| 스테이블코인 시총 / BTC 시총 | 높을수록 잠재 매수력 풍부 | 낮을수록 추가 매수력 제한 |

**USDT vs USDC**: USDT 공급 증가 = 글로벌(아시아 중심) 수요 증가. USDC 공급 증가 = 미국 기관 수요 증가. 양쪽 모두 증가 = 가장 강한 강세 신호.

### 8. DeFi TVL 의미 (DeFi TVL Significance)

**TVL (Total Value Locked)**: DeFi 프로토콜에 예치된 총 자산 가치.

- TVL 증가 + 토큰 가격 상승: 건강한 성장. 실질적 사용 증가.
- TVL 증가 + 토큰 가격 정체: 수익률 파밍(yield farming)으로 인한 일시적 유입. 지속 불확실.
- TVL 감소 + 토큰 가격 하락: 자금 이탈. 위험 신호.
- TVL 감소 + 토큰 가격 정체: 레버리지 축소(deleveraging). 건강한 조정일 수 있음.

**TVL/Market Cap 비율**: 0.5 이상이면 실질적 이용 대비 저평가 가능. 0.1 이하면 투기 비율 높음.

## 주의사항 / 안티패턴

### 1. 온체인 데이터 ≠ 전체 시장
ETF, CME 선물, OTC 거래는 온체인에 나타나지 않는다. 2025년 기준 BTC 거래의 50% 이상이 오프체인. 온체인 데이터는 **부분적 진실**.

### 2. 엔티티 오분류
같은 거래소의 다른 지갑, OTC 데스크, 커스터디 서비스 등이 잘못 분류될 수 있다. "미확인 고래"의 대규모 이동이 실제로는 거래소 내부 지갑 이동(cold → hot wallet)일 수 있음.

### 3. 시차(Lag) 문제
온체인 데이터 대부분은 일일 단위로 집계. 실시간 트레이딩에는 부적합. 온체인은 **중장기 방향 판단**에 적합.

### 4. UTXO 기반 지표의 ETH 비적용
MVRV, SOPR, HODL Waves 등 UTXO 기반 지표는 BTC 전용. ETH는 계정 모델이므로 별도 지표(예: ETH 2.0 스테이킹 비율) 필요.

### 5. 순환 논법
"고래가 축적하니까 상승" → 상승하면 "고래가 맞았다" → 하락하면 "고래가 함정을 놓았다". 온체인 데이터는 확률적 신호이지 확정적 예측이 아님.
